# 回转半径 \(i\) 预置表

> 单位：cm  
> 用途：长细比 \(\lambda = L_0 / i\)（\(L_0\) 为计算长度，**cm**）  
> 与 `packing_assistant/tools/section_library.py` 一致  

## 常用型钢 \(i\)

| 型号 | \(i\) (cm) |
|------|------------|
| 槽钢 8# | 3.2 |
| 槽钢 10# | 4.0 |
| 槽钢 12# | 4.8 |
| 槽钢 14# | 5.5 |
| 方管 40×40×3 | 1.5 |
| 方管 50×50×4 | 1.9 |
| 方管 60×60×4 | 2.3 |
| 方管 80×60×5 | **2.2**（弱轴偏安全） |
| 方管 80×80×5 | 3.0 |
| 角钢 40×40×4 | 1.2 |
| 角钢 50×50×5 | 1.5 |

## 箱型默认

| 箱型 | 框架 \(i\) | 底梁 \(i\) |
|------|-----------|-----------|
| 1.1米框 | 1.5 | 1.5 |
| 铁笼 | 1.9 | 3.2 |
| 2米框 | 3.2 | 3.2 |
| 4米框 | 4.0 | 4.0 |
| 6米框 | 4.8 | 4.8 |

## 判定

```text
λ = L0_cm / i_cm
L0 不确定时 k=1.0（偏安全）

λ < 80～100   相对稳妥
λ > 120～150  警惕失稳，加支撑/加大截面
钢允许上限约 150，木约 120
```
