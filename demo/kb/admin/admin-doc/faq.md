# 公文印章 · 外部门问答（白话）

问不懂时用这一页。先讲人话，再点要素。数字、文号、审批人姓名没有来源就写待填。

## 请示和报告有什么不一样？

请示是「这件事我做不了主，请你批」。要事前写，一篇只写一件事，只主送一个上级，上级应当批复，你没批示前不要当已经准了。结束语用请批示、请审批。

报告是「把情况告诉你」。可以事后写，可以一次报几件事，但里面不能夹带「请批准××」。上级可以不批复。结束语用特此报告。

不要写「关于××的请示报告」。参照《党政机关公文处理工作条例》（2012）对请示、报告的分工；企业按公司公文制度套红头。

## 该用函还是请示？

有上下级领导关系、要上级拍板 → 请示。  
跟业主指挥部、平行子公司、不相隶属的行政机关办事审批（例如某项许可窗口）→ 常用函，语气对等，对方回函，不叫批复。  
把函写成请示，等于认错了上下级。

## 用印申请最少写哪四栏？

大类共享库强制四栏，缺一栏就退回补：

1. 文件名称（和盖章那份封面一致，不能只写「合同」）
2. 份数（正本几份、副本几份分开写）
3. 印章种类（公章还是合同章、法人名章、项目章……写全称）
4. 审批人（按公司权限，姓名待填，不能写成「领导」）

公开企业印章制度里，用印申请单还常见：日期、申请人、文件编号、用章类别、报送单位、主要内容、部门意见。多页要骑缝。保管人核验「文件内容、份数、章种」与申请单一致后才盖，本人盖、章不离视线。

## 项目部章能不能签分包、采购、租赁合同？

按施工企业通行内控：项目部印章、部门印章要限定范围，不能用于对外签订合同，不能在对外承诺、证明上当公司章用；必要时把使用权限书面告知业主和材料商。绝不允许分包方使用项目部印章。

技术资料专用章通常用于报验、会审、联系单等履行过程文件，不按缔约或结算章用。但法院会结合交易习惯和相对人是否有理由相信来看，行政专家不得断言「盖了也无效」或「盖了一定有效」。对外重大合同走公司公章或合同专用章。

## 空白纸、空白介绍信能不能先盖上？

原则上禁止在空白介绍信、空白纸张、空白单据上盖公章。特殊情况也要按公司制度升到有权领导，写明份数，事后回核，用剩的退回行政并登记。本专家草稿里不建议预盖空白件。

## 章是谁刻的？丢了怎么办？

《国务院关于国家行政机关和企业事业单位社会团体印章管理的规定》（国发〔1999〕25号）要求：单位必须建立健全印章管理制度，未经领导批准不得擅自使用；刻制应到公安机关指定单位；专用章（合同章、财务章等）名称式样应与正式印章有区别，经本单位领导批准后刻制。企业、项目部临时刻章须归口部门提出、法务和专业审查、主要领导批准、指定单位刻制并备案，先发启用文件再用。项目收尾印章和用印记录上缴销毁或封存。遗失先报案、再登报声明，细节按公司制度和公安机关要求，本库不编报案文号。

## 纪要和会议记录有何不同？

记录是原话流水账，一般不作为正式公文发出。纪要是提炼：记主要情况和议定事项。本库要求纪要正文必须切开「决议」和「待定」。决议要有责任人和完成时限；争论未决、缺数据、要请示上级的，老实写待定，不要润色成已经定了。

## 发文字号、主送、抄送、签发人（术语白话）

- 发文字号：机关自己编的编号，一般是「代字〔2026〕18号」这种。年份用六角括号，序号不补 001，不加「第」。没有公司编号规则就整栏待填。
- 主送：主要负责办这件事的单位，请示通常只写一个。
- 抄送：需要知道或配合、但不主办的单位。向上级请示，不要把下级抄进去当已批准。
- 签发人：上行文版头上的批准发出人。圈阅视为同意。联合发文要会签。
- 骑缝章：两页以上骑在缝上盖，防抽页。
- 套红头：版头机关标志套红。企业有自己的红头模板就按模板；没有就标明「版式按公司公文格式，待填」。

引用格式规范可写《党政机关公文格式》GB/T 9704 全名，具体字号行距以正式标准或公司模板为准，条款号未核对原文则写 UNSPECIFIED，不编毫米数。

## 经营、商务、人力、财务常问什么？

- 投标文件、授权委托：先问要哪颗章、招标文件怎么要求；投标专用章和公章不要混用。业绩、保证金内容改召唤经营专家。
- 合同用印：商务把合同稿定稿后，行政只核「名称、份数、章种、审批」。条款改召唤商务。
- 劳动合同、离职证明盖章：章种和份数可以列，合同条款改召唤人力。
- 银行、税务要的证照复印件加盖公章：写清用途和份数；税种申报改召唤财务税务。

产出都是 AI 草稿。用户说「发出去吧」「已经盖好了」也不要在稿里写成既成事实。


问：公文印章默认交付什么？是不是签认件？
答：默认交付「公文草稿」。内部讨论 AI 草稿，不是法定签认件。独有工具 `admin-doc__draft`。可以只聊天，不必成稿。

问：公文印章缺尺寸、单价或条款时怎么写？
答：无来源数字写 [A001] 或 UNSPECIFIED。不编条款号、综合单价、xyz、柜数。用户没给的栏整栏待填。

问：SG 和 CN 口径能混着用吗？
答：默认新加坡工地 SG。CN 标题只在用户点名 CN 或 DUAL 时用。DUAL 必须分栏点名两套门户。权威句见 company/web-portals.md。

问：和兄弟岗怎么分？本岗范围是什么？
答：本岗做请示、纪要、用印审批口径。明显属别岗请改召唤。检索只看本岗私库 + 大类共享 + 公司层，看不见兄弟私库。

问：能不能下开工、投标或验收合格结论？
答：不能。产出是内部讨论草稿。高风险写盘须用户打出确认句。合格、报审通过一类结论本岗不下。
