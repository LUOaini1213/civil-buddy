# 外部门怎么问行政

全企业任何人都可以问行政专家，不限于办公室。已召唤的专家只读本岗私库、行政大类共享库和公司库，不读取别岗私库。问题明显属于别的专业时，先答行政边界，请用户在左侧改召唤那位专家。

## 问公文印章（admin-doc）

经营、商务、项目、人力、资料、财务来问下面这些，由公文印章专家答：

- 这份东西该写成请示、报告、通知、函，还是会议纪要？
- 标题、主送、抄送、发文字号、签发人怎么摆？红头按哪套制度？
- 用印审批要填哪些栏？该盖公章、合同专用章、法定代表人名章，还是项目部章、技术资料专用章？
- 投标文件、中标通知回执、授权委托书、介绍信能不能盖项目部章？
- 会议已经开完，纪要里哪些算「已决议」，哪些必须写成「待定」？
- 空白介绍信、空白合同、空白纸能不能先盖章？

答的时候只给文种、要素和审批口径。不代替法务认定合同是否成立，不代替商务写合同条款，不编企业发文字号和审批人姓名。

## 问会务后勤（admin-office）

施工、调度、项目经理、人力、经营来问下面这些，由会务后勤专家答：

- 开生产会、图纸会审、业主检查，会场、议程、席卡、投影、签到、纪要员怎么排？
- 业主、监理、检查组来工地，接待清单要列哪些人、哪些场所、哪些费用栏？
- 出差、驻场、迎检走访，差旅申请单要写什么？标准数字找谁？
- 项目部食堂、宿舍、办公区、劳保日用品、打印耗材谁管？
- 项目车辆、通勤车、迎检用车，派车单要填什么？

答的时候只出清单和检查项。不编住宿伙食标准、不编食堂许可结论、不编车辆保险理赔结论。

## 该改召唤别人（行政先划界）

| 来问的事 | 行政能说的边界 | 改召唤 |
|----------|----------------|--------|
| 报销发票、差旅补助金额、业务招待费入账 | 只列申请单应有栏目 | 财务·核算 `finance-book`；税务发票问 `finance-tax` |
| 劳动合同、工资、社保、招聘简章 | 入职材料用印要素可以列 | 人力 `hr-labor` / `hr-recruit` |
| 分包/采购/租赁合同条款、结算盖章效力 | 只说项目部章通常不得对外签约 | 商务 `subcontract` / `variation` / `cost`；采购 `proc-vendor` |
| 投标保证金、业绩、废标 | 投标文件用哪颗章可以答 | 经营 `bid-parse` / `bid-compliance` |
| 监理通知回复、验收资料目录 | 资料用章种类可以答 | 资料监理 `supervision` |
| 危大方案、交底签认 | 行政不出签认件 | 施工 `construction` / 安质环 `safety-brief` |
| 账号权限、备份 | 不管信息系统 | IT `it-ops` / `it-data` |
| 特种设备、仓库领料 | 办公耗材可答；设备证件不答 | 物机 `equip` / `warehouse` |

## 提问时尽量带上

1. 单位全称、项目名称、发文对象是上级、平级还是业主/分包。
2. 要盖哪颗章、文件全称、页数、份数、是否骑缝。
3. 会议：时间地点、主持人、参会名单、要不要出纪要。
4. 接待/差旅：来访或出行事由、人数、是否住宿用餐（金额一律待填）。
5. 公司用印制度或办公制度若已有，贴原文或路径；没有就写「按公司制度，节点待填」。

不要把「帮我盖个章」说成已经批准。行政专家出的是内部讨论草稿，不是已签发红头，也不是已用印原件。
