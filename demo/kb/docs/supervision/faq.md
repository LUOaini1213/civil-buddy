# 资料监理 · 问答与术语白话

给外部门问「不懂」时用。先讲人话，再点规范名称。不给合格结论，不签发。

## 术语白话

- **检验批**：同一班组、同一做法、同一时段里抽出来检查的一小批活。像一锅菜先尝几口。上面再合成「分项→分部→单位工程」。划分宜按工程量、楼层、施工段；方案要监理审，本岗只列目录。
- **隐蔽**：活做完会被下一道盖住（钢筋、防水、预埋管）。盖之前要通知监理看，留下验收记录，再往下做。没有这份纸，后面很难证明做过。
- **见证取样**：该送检的试块、试件、材料，取样封样送检时，建设或监理的人在场看着。不是资料员自己在办公室填一张单。样品真不真，问 `lab-sample`。
- **复验**：材料进场先看外观和合格证，再按规定抽样送到试验室检。合格证≠复验报告。
- **主控项目 / 一般项目**：主控是安全、节能、环保、主要功能，抽检要全过；一般项目是其余项，允许按专业规范看合格点率。本岗不判点，只检查有没有对应记录。
- **旁站 / 巡视 / 平行检验**：旁站=关键工序监理站旁边看；巡视=定期不定期转场；平行检验=监理对同一项自己再检一遍。这些是监理资料，施工方收副本、对闭合。
- **监理通知单 / 回复单**：监理指出质量、安全或管理问题，要求整改的指令；施工方书面说明怎么改、改完没有、附证据。回复是草稿，待持证人员签发。
- **工程暂停令**：比通知单更重，局部或全面停。不能当普通通知随便回一句「已整改」。复工另走报审，本岗不写「可以复工」。
- **闭合**：发出去的问题有回执、有整改、有证据、有复查栏。链条断一节就是没闭合。本岗只标有/缺/待核，不替监理写「同意闭合」。
- **组卷 / 立卷**：按文件自己长出来的顺序分类装订成卷，方便保管查阅。一个建设工程多个单位工程时，按单位工程组卷。卷别太厚、重份、金属钉，城建档案常卡。
- **竣工图**：按实际做成什么样改过的图，不是把施工图复印盖个章。有变更要标明依据；改得太多应重绘。要盖竣工图章。
- **预验收**：总监组织的竣工预检，内部找问题。正式竣工验收由建设单位组织。城建档案还有一次档案预验收，未获认可文件，按归档规范口径不得组织竣工验收——是否已取得认可，用户未给就待填。
- **报审**：把方案、资料送给监理审。本岗只出目录和草稿，禁止说「报审通过」。

## 外部门常问

**施工员：检验批资料谁先填？**  
现场质量员、工长先有检查记录，再组检验批验收记录，专监组织验收。本岗帮你对：部位、编号、附件（原材、隐蔽、试验）齐不齐。怎么验走 `quality`。

**试验室：报告怎么对到检验批？**  
报告编号、取样部位、代表数量、日期要和进场报验、检验批附件对得上。编号以试验室台账为准，本岗不编号。问台账走 `lab-record`，问取样走 `lab-sample`。

**商务：计量差哪本资料？**  
常见缺：隐蔽、影像、变更依据、试验报告、报验闭合。本岗出缺项表。数量和金额走 `interim` / `cost`，签证走 `variation`。

**安全员：危大要备哪些纸？**  
目录上要有：危大清单、专项讨论提纲、交底目录、检查与整改、论证是否需要（只列栏）。方案正文走 `construction`，是否危大走 `method-hazard`。不要写「已具备论证条件」。

**项目经理：竣工还缺什么才能验收？**  
建质〔2013〕171 号列了一串条件（完成设计和合同、施工竣工报告、监理评估、勘察设计检查、技术档案、主要材料试验和功能检测、按约付款、保修书、住宅分户、监督整改完毕等）。本岗按用户已给清单对缺项，不宣布「可以组织竣工验收」。正式组织是建设单位的事。

**工人：为啥不让浇筑？**  
多半是隐蔽还没人看、或该送的试块没见证。纸没齐，下一道就没有依据。班前口播走 `worker-brief`。

**行政：用印和竣工图章是一回事吗？**  
不是。竣工图章是图上的编制审核监理栏；行政公章走 `admin-doc` 用印流程。

## 回复监理通知怎么写才像闭合

1. 把来文编号、部位、问题一条条复述，不回避。  
2. 原因、措施、时限、谁去做，和来文逐条对应。  
3. 附整改前后照片、记录、需要时的检测报告。  
4. 自检栏和签发栏留给人签。  
5. 复查意见留给监理，施工稿不要代填「合格，同意闭合」。

超时、漏条、照片时间对不上、一份通知塞十几条互不相关的问题，都是常见卡点。时限从来文抄，没有就待填。

## 组卷时别踩的坑

事后一次性补资料、圆珠笔红墨水、复印件当原件又不注明原件处、签字日期和施工日志对不上、有变更无竣工图改绘、有通知无回复、有取样无报告。电子档与纸质应一致；具体格式以当地城建档案馆和用户合同为准。
