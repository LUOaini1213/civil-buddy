# 施工 / 商务 / 工人怎么向各设计专业提问

全企业任何人都可以问已召唤的设计专家。专家用本岗私库白话回答；要成稿才走该岗提纲。已召唤专家不读别岗私库——问错专业时，改召唤或先找「设计统筹」。

本页只讲：问谁、带什么、别问什么。不代替法定审图，不编条款号和工程数字。

## 先分诊：房建还是土木

| 你手里的图 | 先找 |
|-------------|------|
| 楼、地下室、机电、装修、幕墙 | 建筑 / 结构 / 给排水 / 暖通 / 电气，外加专项 |
| 地勘、地基、基坑参数 | 岩土勘察（支护图还要结构/施工危大） |
| 路、管线综合、路面 | 市政道路；导改、标志再加交通工程 |
| 桥、隧 | 桥梁、隧道 |
| 堤、闸、泵站 | 水利 |
| 码头、航道、防波堤 | 港航 |
| 会审纪要、变更该不该出图、不知道问谁 | 设计统筹 |

房建施工图审查常用专业：建筑、结构、给排水、暖通、电气；勘察单独。消防、钢结构、园林、幕墙、人防、弱电常作专项或联审。先勘察、后设计。未经审查合格的施工图不得作为施工依据。涉及强制性标准、地基基础与主体结构安全、节能绿色、签章的修改，须送原审查机构。

## 每次提问最少带这五样

1. 部位：轴号、层号、桩号、房间名，不要只说「那边」。  
2. 图号：用户图纸清单里的编号。没有清单，专家不会写「见图 3.2」。  
3. 你想干什么或看见了什么。  
4. 已经问过谁、有没有变更/洽商。  
5. 是否可能碰到承重、防火疏散、人防、基坑、有限空间、交通导改——碰到就说，不要藏。

## 按专业：外行人怎么开口

**建筑**：功能能不能改、墙是不是防火/疏散、无障碍坡道、门窗表。别问配筋。  
**结构**：能不能开洞、荷载变了没有、植筋代换。无地勘别逼他报承载力。  
**岩土**：持力层、降水、与报告不符的土层。别逼他估桩长。  
**给排水**：出户标高、接市政、消火栓喷淋系统有几套。无标高别要管径。  
**暖通**：冷热源型式、排烟窗谁落图、风管与吊顶。无负荷别要主机型号。  
**电气**：变压器原则、消防电源、防雷接地。无负荷别要容量。  
**消防**：分区、出口、能不能摆货挡门。别要「保证过消防」。  
**钢结构**：节点型式、防腐防火谁先做。无跨度别要截面。  
**园林**：树能不能种在消防路上、覆土够不够。别要成活率承诺。  
**市政道路**：横断、管线谁让谁、缘石坡道。别要编坡度和管径。  
**桥梁 / 隧道**：工法、支护、支座伸缩缝。无跨径地质别要尺寸。  
**交通**：导改几期、标志标线。无流量别要饱和度。  
**室内**：隔墙界面、防水、综合天花。别拆承重墙。  
**幕墙**：预埋偏了怎么办、开启扇能不能封。无风压别要玻璃厚。  
**弱电**：子系统清单、门禁消防释放、桥架。别要品牌。  
**人防**：穿墙密闭、人防门被挡。别要防护等级。  
**水利 / 港航**：堤还是码头、接头谁出图。无水文波浪别要高程桩长。  
**设计统筹**：不知道问谁、会审还是变更、纪要怎么写。

## 施工技术员

会审必须在开工前对着审查合格图做。纪要写清：图号、问题、责任专业、要不要变更图、时限。口头答应不能施工。管线碰撞先提资再改图。

## 商务 / 造价

设计专家不编综合单价、钢筋含量、苗木单价、电缆长度。只能问：有哪些系统、哪些专项、哪些暂定。量价走商务岗；无图写 TBD。不要拿会审里的「研究」当已批准变更去报量。

## 工人 / 班组

听不懂图例就问白话。下列事项停手再问：砸墙开洞、改管径坡度、钢筋代换、拆防火门闭门器、封安全出口、挖到不明管线或与地勘不符的土、人防墙穿管、钢结构气割扩孔。没有变更单按原图。

## 不要问出口的话

- 「按经验给个数就行」——缺失写 [Axxx] 或让你补资料。  
- 「帮我编一条规范号」——只列族名 GB / JGJ / JTG / CJJ 等。  
- 「写上保证通过审图/消防/人防」——禁止。  
- 「别走变更，纪要里改改」——涉及安全与强条必须变更并视情况复审。
