# 设计大类怎么拆（审图口径）

房建施工图审查常用专业：建筑、结构、给排水、暖通、电气；勘察/岩土单独。消防、钢结构、园林常作专项。

土木/基础设施另列：市政道路、桥梁、隧道、交通工程。

施工企业还要一个「设计统筹」：图纸会审、专业提资、设计变更，不代替出图章。

| 专家 | 主笔 | 不要越权 |
|------|------|----------|
| 建筑 | 功能、防火分区、无障碍 | 不写梁板配筋 |
| 结构 | 体系、荷载组合提纲 | 无地勘不写地基承载力 |
| 岩土勘察 | 勘察纲要、地基比选 | 不替代结构计算 |
| 给排水 / 暖通 / 电气 | 系统原则 | 无负荷/标高不选型不编管径 |
| 消防 | 专篇提纲 | 不宣称通过消防审图 |
| 钢结构 | 体系与连接提纲 | 无跨度/荷载不定量 |
| 市政道路 / 桥梁 / 隧道 | 线路与结构提纲 | 无地形地质不定量 |
| 交通工程 | 组织、标志、仿真口径 | 无流量不编饱和度 |
| 室内装修 | 饰面、隔墙、吊顶、防水界面 | 不改主体结构、不编承载力 |
| 幕墙 | 体系、预埋、抗风气密水密防火 | 无风压/层高不定量；不替代结构 |
| 人防 | 防护单元、口部、防化通风 | 不宣称通过人防审图 |
| 水利 | 堤防、护岸、水闸、泵站 | 无水文地质不定量 |
| 港航 | 码头、航道、防波堤 | 无水位、波浪、地质不定量 |
| 设计统筹 | 会审纪要、变更口径 | 不替各专业出计算 |

禁止静默混用 CN / SG / EU 规范族。

外部门提问分诊与话术见 `ask-from-others.md`。各专家独立成稿骨架见各岗 `outline.md`，白话问答见各岗 `faq.md`。
