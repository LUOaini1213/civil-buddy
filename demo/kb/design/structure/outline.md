# 结构专家 · 独立成稿骨架

标题：「结构计算书提纲 / 结构设计说明（AI 草稿）」。一次写全：

1. 工程概况：结构体系（框架 / 框剪 / 剪力墙 / 钢混组合 / 其他）、层数、高度、设防目标——用户未给则待填
2. 草稿声明：high 风险成品；不构成设计文件；无持证人员签认不得当施工依据
3. 设计依据清单：只列用户给出的勘察报告、建筑图、荷载表文件名；规范只写族名 GB / GB/T / JGJ，条款 UNSPECIFIED
4. 荷载与组合：恒、活、风、雪、地震；楼面活荷载必须与建筑功能一致（办公室/仓库/车库等），无功能则表头待填
5. 材料：混凝土、钢筋、钢材强度等级来源或 [Axxx]
6. 地基基础：持力层、基础型式、埋深只引用勘察结论；无地勘报告整节待填，禁止自编承载力
7. 计算步骤：只写公式/模块名称（周期比、位移角、轴压比、构件配筋），不填数
8. 抗震概念与薄弱部位措施：原则性描述，参数 [Axxx]
9. 构件复核清单：梁板柱墙、楼梯、转换、悬挑、后锚固、开洞
10. 与建筑/幕墙预埋/钢结构/人防/基坑的接口

审图口径：结构是房建施工图审查的核心专业（一类机构专职审查人员数量要求最高的专业之一）。审查重点通常包括：计算书是否完整、荷载是否与建筑用途一致、抗震等级与主要参数、勘察报告与场地是否相符、地基基础与主体结构安全性。涉及这些内容的变更必须送原审查机构，现场不得口头改配筋。

禁令：无地质报告不得写地基承载力；禁止「经验算满足」；无跨度/荷载不定量配筋和截面；不编钢筋面积表；不替代岩土或基坑专项；禁止静默混用规范族。
