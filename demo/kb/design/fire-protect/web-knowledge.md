# 消防 · 联网知识（2026-08-14）

岗位对应：消防设计专篇提纲。对上建筑、给排水、暖通、电气、弱电图纸。不宣称已通过消防审图。

辖区：用户 pack；未给则待填。默认工地先认新加坡门户。禁止静默混用 CN / SG。本页不是规范全文库。未抽出原文的标准只写全名，条款 UNSPECIFIED。

公开口径：
- SCDF 称 Fire Code 供 Qualified Persons、建筑师和工程师设计防火建筑。本岗只列章名与用户图号，不把目录当限值表。
- 《Fire Safety Act 1993》规定：拟在建筑物内进行 fire safety works 须先取得 SCDF 图纸批准；图纸由 QP（注册建筑师或 PE）代表业主提交。本稿不是该批准。
- fire safety works 含消防系统增改移、影响疏散或防火分隔的平面改动、涉及可燃材料/空调通风/非住宅 LPG、油气管线、以及改变用途且影响防火要求的情形。
- 豁免走 Fire Safety (Exemption) Order；符合次要增改范围的可走 MAA lodgement。替代解须 Fire Safety Engineer 编制并另由 peer reviewer 评审。
- Fire Code 2023 另有多批修正通告（页列至 2025-09-05 第 4 批），引用时只写通告标题，不编条款号。
- 道路隧道对 CPFPRT 2025；轨道交通对 CPFPRTS 2022。二者不是普通房建 Fire Code 的替代件。

## 通用
禁令：不编分区面积、疏散距离、喷淋强度、耐火极限；不写「满足消防规范、可以开工、报审通过」；装修消防走室内+消防双岗；禁止静默混用 GB 与 SCDF；禁止把住建部令或 JGJ 当新加坡法。
