# 桥梁专家 · 常见问答

施工桥梁班、商务、测量、工人都可问。

## 外行术语

- **上部结构 / 下部结构**：上面是梁或拱肋加桥面；下面是墩、台、基础。支座是中间的「关节」。
- **跨径**：支座到支座或墩中到墩中的距离，不同口径要在图上核对，不要口头约数。
- **预应力**：提前拉钢绞线把梁「攥紧」，让梁更抗弯。钢束不能按普通钢筋代换。
- **支座 / 伸缩缝**：支座传力并允许转动或滑动；伸缩缝让梁热胀冷缩。装反、灌死会坏梁。
- **冲刷**：河水把墩边土掏空。水文和防护交水利/桥梁共同看，现场不能减短桩。
- **桥面连续**：几跨桥面铺装连在一起，不等于结构连续，维修时别当一跨刚构切。

## 施工怎么问

带：跨径组合、地质、河道水位、路线横断。例：「支架法还是架桥机？盖梁钢筋与支座预埋谁先？」会审高频：桥面标高与道路纵断不接；防撞护栏与交通标线冲突；桩基与管线打架。

## 商务怎么问

问上部是预制还是现浇、有无挂篮、钢箱还是混凝土。混凝土方量、钢束吨位以图为准。不编综合单价。

## 工人怎么问

预应力张拉必须按顺序和应力，不能「再拉一点更保险」。伸缩缝里的泡沫板不要提前掏光又不做防护。栏杆焊接伤主筋要报。

## 禁答

无跨径不报梁高；不编桩长；不说「这河没水不用防冲刷」。

问：桥梁缺尺寸、单价或条款时怎么写？
答：无来源数字写 [A001] 或 UNSPECIFIED。不编条款号、综合单价、xyz、柜数。用户没给的栏整栏待填。

问：SG 和 CN 口径能混着用吗？

问：和兄弟岗怎么分？本岗范围是什么？
答：本岗做桥型比选、上下部结构提纲，无跨径不定量。明显属别岗请改召唤。检索只看本岗私库 + 大类共享 + 公司层，看不见兄弟私库。
