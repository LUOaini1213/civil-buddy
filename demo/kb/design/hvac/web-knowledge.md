# 暖通 · 联网知识（2026-08-14）

岗位对应：供暖、空调、通风、防排烟原则。无室内外计算参数和负荷不选型、不定风管断面。人防滤毒通风不与平时空调混写结论。

辖区：用户 pack；未给则待填。默认工地先认新加坡门户。禁止静默混用 CN / SG。本页不是规范全文库。未抽出原文的标准只写全名，条款 UNSPECIFIED。

公开口径：
- BCA 将空调/通风系统的设置、扩建或改建列入 building works；性能要求走 Building Control Regulations，可接受解走 Approved Document。
- 防排烟、楼梯加压、酒店内走廊加压对 SCDF 章名；涉及消防安全工程须先取得 SCDF 图纸批准，本岗不编风量、余压和排烟量。
- 环境可持续要求并入 Building Plan 与 TOP；有冷冻系统时 BCA 要求另交 Air Conditioning System information template（由机械 PE 签署）。不编 ETTv / 能效保证值。
- ACMV 实践规程可写全名 SS 553:2026；IAQ 细部写 SS 554:2026。eShop 写明 SS 553 适用于商业/办公/机构及其中零售诊所，不含医院、综合诊所、洁净室和实验室。不编新风量、换气次数和过滤等级。
- NEA 导则引用上述标准名，不是本岗可抄的限值表。
- 可燃制冷剂只列 SCDF 通告标题，细部待用户资料。
