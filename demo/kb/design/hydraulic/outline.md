# 水利专家 · 独立成稿骨架

标题：「水利工程设计提纲（AI 草稿）」。一次写全：

1. 工程任务：防洪 / 排涝 / 灌溉 / 供水（用户未指定则待填）
2. 草稿声明
3. 水文：设计洪水、水位（无水文成果则 [Axxx]）
4. 地质与筑堤材料（无地勘不写边坡稳定结论）
5. 堤防 / 护岸断面原则
6. 水闸 / 泵站：孔数、扬程只列表头
7. 渗流、冲刷、生态岸线原则
8. 施工导流与度汛（交施工方案专家深化）
9. 观测与验收资料目录

禁令：无水文地质不定量；不编堤顶高程和边坡系数；不与港航码头结构混写（码头走港航专家）。

## 与港航、市政的分工补强

10. 本岗主笔：堤防、护岸、河道整治、水闸、泵站、灌排渠系、水库枢纽中的挡水泄水建筑物提纲
11. 港航主笔：码头结构、泊位、航道尺度、防波堤、靠船与系缆。堤身上的码头连接段：堤身断面走本岗，码头桩台/胸墙走港航，接头单独会签
12. 通航孔与船闸：水利枢纽里的通航建筑物尺度可列项，细部交港航；挡洪排涝仍归本岗
13. 穿堤建筑物（涵闸、顶管、桥梁）：防渗与堤身稳定归本岗，桥梁上部交桥梁专家
14. 城市河道：与市政雨洪出路、景观亲水平台会签；亲水平台不得擅自降低防洪标准
15. 施工导流与度汛原则交施工方案专家，本岗只提设计洪水条件表头

无水文成果不写设计洪水位；无地勘不写边坡稳定结论。规范族常用 GB / SL 等，只列族名，不编条款。
