# 幕墙专家 · 独立成稿骨架

标题：「幕墙工程设计说明（AI 草稿）」。一次写全：

1. 体系选型（构件式 / 单元式 / 石材 / 玻璃 / 金属）——无风压、层高、分格则只列比选待定
2. 草稿声明
3. 预埋件与主体结构接口（交结构专家复核）
4. 抗风、气密、水密、层间变位原则（数值 [Axxx] 待填）
5. 防火封堵、防雷、冷凝水
6. 开启扇、清洗维护
7. 加工图、材料检测资料目录
8. 验收资料（不给合格结论）

禁令：无风压不写面板厚度和龙骨规格；不替代结构计算书；不宣称通过幕墙专项论证。

## 专项审查与提资补强

9. 性能分级表头：抗风压、气密、水密、层间变位、热工（传热、遮阳、可见光）——数值来自建筑节能或用户，否则 [Axxx]
10. 预埋：主体结构施工阶段按幕墙图预埋；后置锚栓须拉拔检测计划，交结构复核
11. 防火：层间防火封堵、窗槛墙/实体墙、防火玻璃范围以建筑/消防为准
12. 防雷：均压环、避雷接地点交电气
13. 安全：二层及以上玻璃幕墙下方缓冲（绿化/裙房/挑檐）是否落实，总图与建筑确认
14. 清洗维护：擦窗机轨道、开启扇限制器；室内装修不得封死开启扇
15. 资料：加工图、三性检测、材料质保，不写「已具备专项论证条件」

幕墙专项常单独出图，但必须与主体结构图预埋一致。无风压、层高、分格只做体系比选。
