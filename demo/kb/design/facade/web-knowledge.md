# 幕墙 · 联网知识（2026-08-14）

岗位对应：幕墙体系、预埋、抗风/气密/水密/防火封堵原则。无风压、层高、分格只做比选。不替代主体结构计算。

辖区：用户 pack；未给则待填。默认工地先认新加坡门户。禁止静默混用 CN / SG。本页不是规范全文库。未抽出原文的标准只写全名，条款 UNSPECIFIED。

公开口径（38号通知原文口径，不编条款号，不把场所限制写成未给项目的已判定结论）：
- 新建住宅、党政机关办公楼、医院门诊急诊楼和病房楼、中小学校、托儿所、幼儿园、老年人建筑，不得在二层及以上采用玻璃幕墙。
- 人员密集、流动性大的商业中心、交通枢纽、公共文化体育设施等场所，临近道路、广场及下部为出入口、人员通道的建筑，严禁采用全隐框玻璃幕墙。
- 二层及以上应考虑下方绿化带/裙房/挑檐等缓冲。宜采用夹层玻璃、均质钢化玻璃或超白玻璃。
- 新建幕墙应加强方案设计、施工图与施工方案的安全技术论证，竣工前专项验收。既有幕墙安全维护实行业主负责制。
- 《民用建筑通用规范》为强制性工程建设规范；与现行标准不一致时以该通规为准。

公开口径：
- 外墙耐火与开口保护对 SCDF 章名 External Wall / Protection of Openings / Fire Stopping。外墙饰面另有 SCDF 通告标题 Advisory on the Use of External Wall Finishes on Facade of Buildings。本岗只写章名与通告标题，不编燃烧等级、耐火小时数、开敞面积比。
- 热工/节能对 BCA 环境可持续标题与 Code on Envelope Thermal Performance for Buildings。适用门槛与采用哪一版 Code for Environmental Sustainability of Buildings 取决于首次向 URA 申规划许可的日期（页表：2021-12-01 起用第 4 版）。2021-12-01 起门槛写 GFA 5,000 m² 及以上新建/扩建/重大改造；2008-04-15 至 2021-11-30 为 2,000 m²。本岗不编 ETTv/RETV 保证值。
- GLS 地块另有 Mandatory Higher Green Mark Standard 标题，不把营销级 Green Mark 当幕墙计算书。
- 无风压不写面板厚度和龙骨规格。不替代主体结构计算书。
