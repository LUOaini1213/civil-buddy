# 设计统筹 · 联网知识（2026-08-14）

岗位对应：会审纪要、提资清单、设计变更口径。不代替各专业出计算、不出图章。先有审查合格施工图再会审。

辖区：用户 pack；未给则待填。禁止静默混用 CN / SG。本页不是规范全文库。

公开口径：先勘察、后设计、再施工。施工图设计文件未经审查批准的，不得使用。建设单位、施工单位、监理单位不得自行修改勘察设计文件；确需修改的，由原勘察设计单位修改。设计单位应当在施工前向施工、监理说明设计意图。涉及审图办法所列内容的修改须送原审查机构。本岗不宣称变更「不用再审」，不写「可以开工 / 报审通过」。

公开口径：
- BCA 性能要求 + Approved Document 可接受解；消防另走 SCDF，给排水另走 PUB，道路另走 LTA。工地安全走 MOM，不是出图替代。
- CORENET X COP 现列 3.1 Edition（2025-12）。COP 自称不替代各局 Codes / Acts / Regulations；跨部门冲突可走 IACC，本岗不代裁决。
- 强制网关以较新联合通告为准：2025-10-01 起 GFA ≥ 30,000 m² 新项目已强制走 CORENET X Gateway Processes（已实施）。2026-07-23 DC26-08 更新：2026-10-01 起强制范围为 GFA ≥ 5,000 m² 的新项目（新建总 GFA、新增 GFA 或重大 A&A 受影响/置换 GFA 达该门槛）。GFA < 5,000 m² 可继续走 CORENET 2.0，Gateway 为自愿。2026-09-30 前已在 CORENET 2 起步的 ≥ 5,000 m² 项目可暂续走 CORENET 2。不得再按 DC25-07 旧表写成「2026-10-01 起全部新项目不论面积都必须上 CORENET X」。
- BCA Building Plan 页（2026-07-06）尚未改写 2026-10-01 门槛，引用时与 DC26-08 对照，不把旧页当最新实施计划。
- 变更是否需再提交以 QP/主管部门为准，本岗不口头放行。
