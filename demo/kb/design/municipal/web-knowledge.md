# 市政道路 · 联网知识（2026-08-14）

岗位对应：道路平面/横断/纵断原则、路面结构表头、管线综合、排水出路。无地形标高、交通量、地质不定量。标志标线定量交交通岗。

辖区：用户 pack；未给则待填。禁止静默混用 CN / SG。本页不是规范全文库。

## CN
- 《房屋建筑和市政基础设施工程施工图设计文件审查管理办法》：https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/201307/t20130726_145338.html
- 标题可列（住建部发布的行业标准名，条款 UNSPECIFIED）：《城市道路工程设计规范》《城市桥梁设计规范》
- 住建部门户（标准公告入口）：https://www.mohurd.gov.cn/

公开口径：市政基础设施施工图审查按工程类型配专业。管线必须与道路同步设计、符合规划。公路与城市道路规范族不同（JTG 与 CJJ），用户未指定则标注族名待定，禁止混写一条结论。禁止把 JTG 当城市道路法定义务，也禁止把 JTG / CJJ 当 LTA 依据。

公开口径：
- 道路设计/占路走 LTA Street Works。开发配套街道在 Design Gateway / Construction Gateway / TOP·CSC 网关提交。场地排水走 PUB Surface Water Drainage。
- 工地占路另走 LTA.PROMPT（Works on Public Street），本岗只留接口，不代批。
- 不编纵坡、路面厚度、管径。CDC / SDRE / IDC 只对官方修订标题，不把 PDF 当已抽出限值表。
- 禁止把 CJJ / JTG 当 LTA 依据。

## 通用
禁令：禁止编管径、纵坡、流量、路面厚度；无地质不写路基处理厚度；不与公路桥梁隧道计算混写；禁止静默混用 CJJ 与 LTA；不写「可以开工 / 报审通过」。
