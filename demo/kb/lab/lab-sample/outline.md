# 见证取样专家 · 独立成稿骨架

标题：「取样送检清单（AI 草稿）」。风险 high。本清单只排计划与缺口，不判定材料合格，不编组数和代表数量。不贴检测规程全文。一次写全：

1. 封面：工程名称、施工段、计划周期、检测机构名称（须用户给出且为建设委托）。空签认栏。草稿声明用公司 disclaimer。
2. 角色：取样员属施工单位；见证人属建设单位或监理。取样、见证应对试样代表性和真实性负责。公开管理口径（住房和城乡建设部《建设工程质量检测管理办法》，2023-03-01 施行）：建设委托的检测，施工人员须在见证下现场取样；见证人做见证记录并签字；试样要有清晰、不易脱落的唯一标识和封志；委托单须送检人、见证人等签字；检测机构收样时核试样、标识、封志，不符不受理。
3. 必须纳入见证取样的类别（全国公开底线，建建〔2000〕211 号第六条，只列名称不展开试验方法）：承重结构混凝土试块；承重墙体砌筑砂浆试块；承重结构钢筋及连接接头试件；承重墙的砖和混凝土小型砌块；拌制混凝土和砌筑砂浆的水泥；承重结构混凝土用掺加剂；地下、屋面、厕浴间防水材料；国家规定的其他项目。地方清单常加长（砂石、节能材料、钢结构连接件等），以项目所在地现行规定为准，用户未给地方文件则加「地方加长项待核」，不编造地方条款。
4. 比例口径：涉及结构安全的试块、试件和材料，见证取样和送检比例不得低于有关技术标准中规定应取样数量的 30%（建建〔2000〕211 号）。30% 是下限不是「只做三成就够」；保障性住房等地方要求可能提高到全部见证。具体每批组数按该项现行标准 + 用户计划，缺则 `[Axxx] 待填`，禁止专家估算组数。
5. 现场动作提纲：按计划取样 → 标识封志（工程名称、部位、日期、样品名称数量、取样人与见证人签字）→ 共同送检 → 填委托单 → 检测机构核封志。重要材料宜留取样过程影像（地方常见要求，非本库编造的全国强制数字）。试样损伤、超时、掉封不得当见证样。
6. 不合格升级：样品或报告不合格，24 小时内上报（大类 lab-rules），停止相关加工与使用，书面通知监理/建设，隔离待处置。能否双倍复检以该项现行标准为准（有的项目如钢筋重量偏差公开资料写明不得复检），本清单不代做复检结论。涉及结构安全、主要使用功能的不合格，检测机构还须按管理办法向工程所在地县级以上住建主管部门报告——项目试验室负责把报告送达路径写进清单，不冒充主管部门。
7. 报告效力：见证取样检测报告须加盖见证取样检测专用章。非建设单位委托的检测报告不得作为工程质量验收资料。出厂合格证、供方自检不能替代见证送检。
8. 与配比、台账、仓管、资料的接口：未复试或不合格的原材料，lab-mix 不得出施工配比；报告编号连续登记走 lab-record；实物隔离走 warehouse；资料目录走 supervision。本岗不读那些私库，只留接口栏。

禁令：不编「已取样合格」「可以用于工程」；不编检测数据；不把监督抽检、企业试验室自检、见证取样混成一种报告；取样员与见证人不得写成同一人同一单位。
