# 周月计划 · 联网入口（2026-08-14 现场）

岗位对应：四周滚动、周承诺、制约清除与交叉窗口。窗口长度以用户制度为准，禁止用周计划改合同工期，禁止编作业持续天数。

辖区：默认新加坡工地（SG）。用户 pack 另指定则从其指定。禁止静默混用 CN / SG。本页不是规范全文库。未抽出原文的标准只写全名，条款 UNSPECIFIED。

## 通用 · Last Planner System®（只作方法名）

- LCI 官方页：五句对话——Pull 定 **Should**；Make-ready 使 **Can**；Weekly Work Plan 承诺 **Will**；日站会看 **Did**；未完成原因 **Learn**。末位计划员是最靠近作业、有权作可靠承诺的人。不是 BCA / PSSCOC 法定档。https://leanconstruction.org/lean-topics/last-planner-system/
- LCI Standard Work · Lookahead（本轮打开公开 PDF）：展望是使「该做的活能做」——提前清制约。页述窗口通常 **3–12 周**，多数项目偏好 **6 周**；每周前推，始终看到窗口末端新作业。该数字是方法说明，**不是本岗强制四周**。https://leanconstruction.org/wp-content/uploads/2022/08/7_LPS_Lookahead_Planning.pdf
- LCI Standard Work · Weekly Work Plan：WWP 比展望更细，是承诺层，也是算 PPC（完成项/承诺项）的分母。只有已具备条件、由末位计划员认领的条目才进本周承诺。https://leanconstruction.org/wp-content/uploads/2022/08/9_LPS_Weekly_Work_Planning.pdf
- LCI 行业观察：传统周计划兑现率往往偏低（官方页写过约 54%）。该数字是观察，不是本岗工期承诺，也不得抄进项目横道。
- 国内口头多说「四周滚动 + 月计划」。LCI 不强制四周；本岗不规定必须四周。

## SG

- BCA PSSCOC 门户（页更 **2026-03-14**）：周计划仍须挂在合同 **Clause 9 Programme for the Works** / 总控版本下；修订合同竣工日走 **Clause 14 Time for Completion**，不在周报改。https://www1.bca.gov.sg/growth-and-transformation/procurement/standard-contract-forms/public-sector-standard-conditions-of-contract-psscoc/
- Building Control (Buildability and Productivity) Regulations 2011 将 digital scheduling / 进度数字化跟踪列为 IDD 用例之一（reg.3A），只作门户，不编软件名。https://sso.agc.gov.sg/SL/BCA1989-S199-2011
- C-Score / 省工工艺窗口可标为制约来源，**不是**周劳动力计划。https://www1.bca.gov.sg/growth-and-transformation/productivity/buildability-and-constructability-framework/
- MOM WSH：工地安全与停工条件只列表头；风速、雨量限值必须来自用户方案或当地规定。https://www.mom.gov.sg/workplace-safety-and-health
- 停工条件（台风、政府令、危大未论证）只列表头，不写「可以开工」。

## CN

- 滚动计划法是现场用法，不是另做一份与总控无关的新工期。施组、项目管理规范只写全名：GB/T 50502-2009、GB/T 50326-2017，条款 UNSPECIFIED。
- 开竣工认定仍用法释〔2020〕25 号第八条、第九条；周报改竣工日期是大忌。https://www.court.gov.cn/zixun/xiangqing/282111.html

## 通用 禁令

- 不把制约未清的工作写入本周承诺。不编班组名单、日顺序、停工风速。不断言本周一定完成或交叉作业已安全。
- LCI 示例表里的人数、楼层、日期是演示，禁止当本项目用量。不写报审通过。
