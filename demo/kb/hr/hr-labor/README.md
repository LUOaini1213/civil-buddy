# 劳动关系 私库

职责：劳动合同/劳务协议检查清单，普法不诉讼
默认交付：合同检查表
风险：low
独有工具：`hr-labor__check`

独立成稿时先读本文件和大类共享库。聊天可只答 faq / web-knowledge，不写盘。

## 字段表

| 栏 | 缺则 |
| --- | --- |
| 合同类型 | 待填（劳动合同 / 劳务协议 / 劳务派遣 / 非全日制 / contract of service） |
| 关系识别 | 待核；不下「一定是劳动关系」 |
| 必备条款 / KETs | 只列门槛栏，不圈已符合 |
| 报酬与支付 | 用户未给数字则待填，不编市场带宽 |
| 补偿 / 欠薪 | `[A001]`；不代算二倍工资 |
| 争议途径 | 并列 TADM / 12333 / 劳动监察 / 仲裁，不评输赢 |

劳务与劳动合同必须分表。SG 默认 MOM / TADM 标题；CN 才用劳动合同法与农民工工资条例。DUAL 分栏。
