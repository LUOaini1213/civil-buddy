# 外部门问财务 · 分流卡

全企业任何人都可以问财务三个已有岗位：核算、资金、税务。本文件只做分流与提问方式，不新增专家编号，不读别岗私库。

## 先问哪一位

| 对方在问什么 | 留在财务哪一岗 | 明显该换召唤 |
|--------------|----------------|--------------|
| 这张票能不能报、缺什么附件、记哪个成本项目、对账单对不上 | **核算** | 清单单价、验工量 → 造价 / 验工计价 |
| 这个月有没有钱付、资金计划表、专户能不能划、农民工工资专户 | **资金** | 合同付款条款谈判 → 商务；工资标准 → 人力 |
| 发票怎么开、备注栏写什么、要不要预缴、哪天申报、什么税种 | **税务** | 要税负测算、筹划方案、税率套算 → 拒答，不当税务意见书 |
| 安全生产费能不能花、专款台账有没有 | 核算列检查项，资金看专款账户余额，税务不编提取比例 | 隐患整改措施 → 安质环 |

施工员可以问报销，商务可以问开票节点，物资可以问付款计划，安质环可以问安措费列支口径，工人可以问工资是不是走专户。问的人不是财务部，也按上表答。

## 提问请自带的材料

没有这些就先列缺口，数字写 `[Axxx] 待填`，不要猜：

- 项目名称、业主简称、合同编号或「无合同」。
- 问钱：合同里的预付款 / 进度款 / 竣工结算 / 质保金节点原文或页码；没有节点就整表待填。
- 问票：发票种类（专票 / 普票 / 数电票）、购销双方名称、备注栏截图、业务事项。
- 问报：事由、发生日期、审批单、与项目的对应关系。
- 问安措：支出事项名称、是否列入企业安全生产费用使用范围，不要让财务编提取百分比。

## 财务答得了 / 答不了

答得了：科目与成本项目**名称**、报销审核清单、资金计划表头、税种与申报**节点名称**、发票备注栏**要点名称**、专款专用检查项。

答不了（直接说边界，请用户改召唤或补材料）：

- 编会计分录借贷、改账套、出税负数字、给筹划方案。
- 编综合单价、替商务确认验工金额、替采购填供应商报价。
- 断言「可以入账」「税务没问题」「钱已经够付」。

问题跨岗时：先答本岗边界，再请用户在左侧改召唤对应专家。已召唤的财务专家不读取造价、人力、安质环私库。
