# 资金专家 · 独立成稿骨架

标题：「项目资金计划草稿（AI 草稿）」。一次写全收支表头，无合同节点则整表待填。

1. 封面：项目、币种、计划期（周 / 月 / 滚动四周）、编制人空栏。
2. 草稿声明：内部讨论，不构成付款指令、银行划款依据或融资承诺。
3. 编制原则名称：以收定支、量入为出、专户分账。没有预计收款节点，不得编「本月可付」结论。
4. 合同价款节点名称（只列名称与日期栏，比例与金额待填）：
   - 工程预付款：有无合同约定、抵扣方式、是否已到账。
   - 工程进度款：按月或按形象进度；计量报告是否已送、业主/监理是否已核。
   - 工程竣工结算款：结算资料是否递交、审查是否完成。
   - 质量保证（保修）金：预留、到期返还。上述节点名称对照《建设工程价款结算暂行办法》（财建〔2004〕369 号）的约定事项清单；具体时限与比例以**本合同及现行有效办法**为准，禁止默写百分比。
5. 收入栏：业主到账、质保金返还、退还的投标/履约保证金、公司拨款。每笔写：节点名称、计划日、到账账户（基本户 / 一般户 / 农民工工资专用账户）、状态（未报量 / 已报未批 / 已批未付 / 已到账）。无证据则待填。
6. 支出栏（分账户，禁止混户）：
   - 基本结算户：材料、专业分包（非工资部分）、机械租赁、现场经费、应缴税费的资金占用（税额本身问税务岗，资金岗只列「申报期备付」空栏）。
   - 农民工工资专用账户：人工费分账拨入、总包代发。对照工程建设领域工资专用账户制度的名称：分账管理、工资专户、总包代发、实名制工资表。专户资金不用于材料款或其他工程款。
   - 安全生产费用：专款支出计划，只列事项名称与「是否在使用范围内」，金额待填。
7. 平衡试算：期初可用 + 计划收款 − 计划付款 = 期末缺口或余量。四格都缺数就写「无法试算」，不要编现金。
8. 风险提示只写条件句：计量未签认则进度款计划日待填；专户未开则工资支出不得列入可付；无三方协议则专户栏待填。
9. 自检：未把商务验工金额当成已到账；未指挥银行划款；未承诺垫资合法。

禁令：无合同节点不编付款承诺；不编利率、融资方案；不把工资专户余额拿去平衡材料缺口；不写「资金充足可以全面开花」。
