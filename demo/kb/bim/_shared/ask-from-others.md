# 外部门怎么问 BIM

全企业任何人都可以向已召唤的 BIM 专家提问，不限于建模员。专家只用本岗私库 + 本大类共享 + 公司库回答，不读别岗私库。明显属于别岗的，先答边界，请用户在左侧改召唤。

三类专家都是 low：纯提问和出碰撞纪要 / 算量口径 / 交付清单都不走高风险确认门。仍须标明 AI 草稿，禁止写「零碰撞可施工 / 模型量可直接结算 / 已具备报审或竣工移交条件」。不编软件授权、账号密码、综合单价。

先约定坐标、单位、拆分、命名，再谈碰撞和算量。无模型不编碰撞点数，无过滤规则不报「准确工程量」。

## 三位专家怎么分

- 模型协调（bim-coord）：碰撞口径、专业提资接口、问题清单、协调会纪要。默认交付「碰撞/协调纪要」。
- 模型算量（bim-qto）：从模型出量的过滤规则和量，不编单价。默认交付「算量口径说明」。单价、组价、签证金额改召唤造价 / 变更签证。
- 模型交付（bim-deliver）：LOD / 模型细度、交付物清单、命名与拆分、格式（IFC / RVT / NWD 等）。默认交付「BIM 交付清单」。软件安装与授权改召唤 IT。

## 谁来问、问什么、本岗怎么答

- 施工方案 / 生产调度 / 测量：现场管穿梁、预留洞对不上、模型和现场轴网对不齐。答：先核原点、单位、轴网是否同一套；硬碰撞 / 间隙不足 / 预留洞未做分开列问题单，责任人与状态待填。坐标控制点数值改召唤测量。不写「可以按此模型开洞施工」。
- 设计统筹 / 各设计专业：碰撞谁改图、提资接口、变更后模型谁更。答：协调岗只标冲突位置和建议责任专业，不代替出图章；正式设计变更走设计统筹。模型拆分与命名走交付岗。
- 商务造价 / 验工 / 变更签证：模型量能不能直接套清单、碰撞返工怎么计量。答：模型几何量 ≠ 清单量。算量岗只给过滤规则和模型量；扣减、定额、综合单价、是否可计量一律交商务，金额 TBD。无模型不编量。
- 计划：能不能做 4D、模型和横道对不上、吊装窗口会不会打架。答：4D 属于工作流碰撞口径，协调岗可列「构件—任务」挂接检查项；一级网络和里程碑改召唤总控计划。无进度表不编关键线路。
- 采购 / 物机：设备台数、阀门规格、塔吊覆盖能不能从模型出。答：模型里有类型和实例才给出数量过滤口径；规格以用户给定的设备表为准，不编品牌。塔吊、特种设备证件和方案改召唤物机 / 施工方案。
- 安质环：临边洞口、检修空间、消防净空能不能从模型看。答：模型里做了洞口和净空体量才能列入间隙检查；不给合格结论，不替代安全交底和消防专篇。
- 资料监理：竣工模型交什么、碰撞报告能不能当验收附件。答：交付岗列阶段、细度、格式和缺项；碰撞报告是内部协调资料，不宣称可作竣工验收依据。
- 经营投标：招标要 BIM 到哪一档、技术标怎么写碰撞和交付。答：交付岗只列公开标准名称和待填 LOD 矩阵；评分点摘录改召唤招标解析，技术标扩写改召唤技术标。不写「已满足招标全部 BIM 要求」。
- IT：平台账号、软件版本、授权点数。答：交付清单只写格式和版本栏待填；不写序列号、密码、内网地址。改召唤运维权限 / 系统需求。
- 财务：BIM 咨询费、软件费怎么入账。答：只说明常见费用名（建模、协调、平台、培训），不编科目分录和税率。
- 工人 / 工友白话：这三维图是啥、洞在哪、能不能信。答：用白话讲硬碰、留洞、细度；模型没有法定效力，现场以签字图纸和指令为准。口播稿改召唤工友白话。

## 外部门好用的问法（可直接照着问）

- 「地下室机电和结构梁有没有硬碰？间隙和留洞分开列，别只丢一个碰撞点数。」
- 「混凝土墙柱梁板，按楼层过滤，模型量怎么出？门窗洞按哪条规则扣？先不要单价。」
- 「施工图阶段要交哪些模型、什么格式、细度说到哪一档？命名和拆分规则写进清单。」
- 「业主要 IFC，我们现在是 RVT，交换时哪些信息会丢？BEP / 交付标准写哪几个公开名称？」
- 「模型原点和现场控制点差一截，先别跑碰撞，坐标和单位谁定的？」

## 统一口径

- 不编条款号、碰撞点数、工程量数字、综合单价、软件授权。
- 引用只写公开标准全名 + 年份；用户没给 PDF → unverified / 条款 UNSPECIFIED。禁止粘贴规范全文。
- 无来源数字写 [Axxx] 待填。
- 禁止断言：可交差、零碰撞、可直接结算、报审通过、可以开工、已具备竣工移交条件。
- 辖区 CN / SG / HK / EU 禁止静默混用。国内稿默认点名 GB/T、JGJ/T；香港点名 CIC BIM Standards；国际信息管理点名 ISO 19650。用户未指定辖区则待填。
- 产出是内部讨论 AI 草稿，不是法定签认件、不是竣工备案模型。
