# 外部门问采购 · 分流口径

全企业任何人都可以向本大类已召唤专家提问，不限于物资部。已召唤专家只读本岗私库、本大类 `_shared` 和公司库，不读别岗私库。问题明显属于别岗时：先答采购边界，再请对方在左侧改召唤。

本大类只有三个已有岗位，禁止发明新专家编号：

| 已召唤 | 答什么 | 默认成稿 |
|--------|--------|----------|
| 采购计划 `proc-plan` | 甲供 / 甲指 / 甲限 / 自采划分、需用计划如何变成采购计划、提前期、到货节点 | 采购计划表 |
| 比价询价 `proc-compare` | 询价函口径、比价表怎么列、依法必须招标还是询比、无报价怎么办 | 比价表草稿 |
| 供应商 `proc-vendor` | 准入资料、考察、短名单、评价与退出 | 供应商评价表 |

## 外部门常问 → 谁答 → 何时改召唤

| 来人（大类） | 常问 | 本大类先答 | 改召唤 |
|--------------|------|------------|--------|
| 施工生产 / 调度 | 现场要料、什么时候到、会不会断供 | `proc-plan`：对齐需用计划与到货节点 | 周月形象进度 → `plan-lookahead`；日报缺料记事 → `dispatch` |
| 计划 | 提前期占不占关键线路 | `proc-plan`：倒排下单日，节点待填 | 一级网络 / 里程碑 → `plan-master` |
| 商务造价 | 合同里哪些甲供、暂估价谁买、认质认价 | `proc-plan` 分列供应方式；`proc-compare` 只比已收到的报价 | 清单组价、综合单价 → `cost`；签证金额 → `variation`；分包结算 → `subcontract` |
| 经营投标 | 业主招标文件里的材料品牌、依法必须招标 | `proc-compare` 说法规名称与适用边界 | 评分点 / 废标雷 → `bid-parse` / `bid-compliance` |
| 财务 | 什么时候付款、要什么发票、能否预付 | `proc-compare` 只列合同/询价里的付款条件，不编账套 | 资金计划 / 现金流 → `finance-fund`；报销科目 → `finance-book`；税票种类 → `finance-tax` |
| 仓管 / 物机 | 货到了谁验收、有没有送货单 | `proc-plan` 写到货与交接栏 | 入库、限额领料、盘点 → `warehouse`；现场耗用节超 → `material-site` |
| 设备 | 塔吊、发电机是买还是租 | 采购只答「采购还是租赁」的计划口径 | 特种设备证件、进场验收 → `equip` |
| 试验室 | 厂家质保书、复试报告跟哪家 | `proc-vendor` 答供方资料是否齐全 | 见证取样、不合格升级 → `lab-sample`；施工配比 → `lab-mix` |
| 安质环 | 安全帽、密目网、危化品谁买 | `proc-plan` 把劳保/危化品单独列项 | 交底 → `safety-brief`；危废/扬尘手续 → `env` |
| 设计 | 图上规格型号能否指定唯一品牌 | `proc-compare` 说明招标文件不得无故锁死唯一品牌 | 规格本身、图则 → 对应设计专业 |
| 行政 | 打印纸、矿泉水、接待礼品 | 先声明：工程物资归本大类，办公后勤不是本岗主笔 | `admin-office` |
| 工人 / 项目经理 | 安全帽谁发、夜班盒饭谁买 | 白话讲「劳保列入采购计划，食堂接待问行政」 | 班前口播 → `worker-brief`；日报 → `pm-daily` |

## 统一禁令（外部门问也适用）

- 无供应商书面报价、无合同单价、无业主书面认价：单价栏写待填 / TBD，禁止编「市场价约 xx 元」、禁止做价格本。
- 甲供、甲指、甲限、自采（乙供）必须分列，禁止混在一行里只写「材料」。
- 比价至少比规格、到货期、质保、付款，不只比总价。
- 办公耗材、食堂接待不在本大类出采购计划正本。
- 不读、不改别岗私库；不新开专家 id。
