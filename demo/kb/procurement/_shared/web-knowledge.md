# 采购大类 · 联网口径（2026-08-14 现场）

条目标辖区。本页只记门户与法规全名，不是规范全文库。无供应商书面报价、无合同单价、无业主书面认价：单价栏待填 / TBD，禁止编「市场价约 xx」。甲供 / 甲指 / 甲限 / 自采必须分列。

## CN

- 中国政府采购网（财政部唯一指定政府采购信息网络发布媒体）：https://www.ccgp.gov.cn/ — 公开招标 / 邀请 / 询价 / 竞争性谈判 / 磋商公告、政采法规、严重违法失信行为记录。
- 全国公共资源交易平台：https://www.ggzy.gov.cn/ — 工程建设与政府采购栏目分开查。
- 中国招标投标公共服务平台：http://www.cebpubservice.com/ — 《招标公告和公示信息发布管理办法》所称国家级汇集媒介之一；依法必须招标项目的公告也可在项目所在地省级电子招投标公共服务平台发布。
- 《中华人民共和国政府采购法》只管国家机关、事业单位、团体组织使用财政性资金的采购。施工企业现场自采主线通常是《招标投标法》或企业采购制度，禁止把政采五种方式直接套到私人买水泥。
- 《必须招标的工程项目规定》（国家发展改革委令 2018 年第 16 号，2018-06-01 施行）第五条：范围内项目的重要设备、材料等货物，单项合同估算价在 200 万元人民币以上必须招标。这是法定规模标准，不是材料信息价。https://zfxxgk.ndrc.gov.cn/web/iteminfo.jsp?id=18461

## SG（2026-08-14 打开过）

- GeBIZ（Government Electronic Business，新加坡政府一站式电子采购）：https://www.gebiz.gov.sg/ — 招标 / 询价 / 资格预审 / 授标公示。回电子标须先注册 GeBIZ Trading Partner（GTP）。
- GTP 注册：https://www.gebiz.gov.sg/ptn/gtpregistration/signup.xhtml ；Supplier Directory：https://www.gebiz.gov.sg/ptn/supplier/directory/index.xhtml
- Guide to Singapore Procurement：https://www.gebiz.gov.sg/singapore-government-procurement-regime.html ；FAQ：https://www.gebiz.gov.sg/faq.html
- MOF Government procurement（页更 2025-10-22）：原则标题 Transparency / Open and Fair Competition / Value for Money。https://www.mof.gov.sg/policies/government-procurement/
- MOF Procurement processes（页更 2025-12-01）：Sourcing / Evaluation / Approval of Award / Contract Management。https://www.mof.gov.sg/policies/government-procurement/procurement-processes/
- 施工相关登记走 BCA，不走 GSR：CRS（页更 2026-08-07）https://www1.bca.gov.sg/growth-and-transformation/procurement/registration-of-built-environment-firms/contractors-registration-system-crs/ ；建材设备供应 SY Registry（页更 2026-07-01）https://www1.bca.gov.sg/growth-and-transformation/procurement/registration-of-built-environment-firms/suppliers-sy-registry/ ；eBACS / e-Directory https://www.bca.gov.sg/eBACS/
- 等级对应投标限额只指向官方页标题，本库不转抄限额表金额：https://www1.bca.gov.sg/growth-and-transformation/procurement/registration-of-built-environment-firms/tendering-limits/ ；明细页标题 CRS, FM, and SY Registries tendering limits（页更 2026-06-16）https://www1.bca.gov.sg/growth-and-transformation/procurement/registration-of-built-environment-firms/tendering-limits/crs-fm-and-sy-registries-tendering-limits/
- BCA Price Quality Method (PQM) Framework（页更 2026-01-26）：公共工程施工评标框架，不是现场材料信息价。https://www1.bca.gov.sg/growth-and-transformation/procurement/procurement-and-legal-frameworks/price-quality-method-pqm-framework/

## 本大类谁用哪页

- 采购计划 `proc-plan`：法定招标门槛、政采预算与提前期、GeBIZ 年度意向清单、MOF 四段流程。
- 比价询价 `proc-compare`：公开招标 / 询价 / Quotation vs Tender 边界；PQM 只作公共工程施工评标标题；无报价不填单价。
- 供应商 `proc-vendor`：GTP / GSR / BCA CRS·SY 准入标题；ISO 9001:2015 第 8.4 条款名；名录与退出。
