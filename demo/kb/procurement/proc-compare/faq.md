# 比价询价 · 白话问答

问：询价和比价是一回事吗？货比三家就行了吧？
答：不是一回事。询价是你先把规格、数量、到货期、质保、付款、验收写成一份口径一致的询价单，发给几家，让人家按同一套条件报价。比价是把收回来的报价摊在一张表上，一项一项看响应还是偏离。只在微信里问「一吨多少钱」再随手填进表，不算询价。行业习惯和企业制度多要求不少于三家；央企询比采购的定义就是 3 家及以上一次报出不得更改的价格。只有两家也能比，但要在表上写「有效报价不足三家及原因」，不要虚构第三家。

问：为什么不能只比总价？
答：总价会被规格缩水、交货拖后、质保变短、款要预付、卸车不管、发票开不出所抵消。大类共享库写明：比价至少列规格、到货期、质保、付款。一家便宜但三个月后才到、还要全额预付，对现场未必合算。没有收到的那一列，就空着或写「未报」，禁止用「市场行情」替人家填。

问：供应商还没回价，领导让先出一张「参考价比价表」怎么办？
答：拒绝编价。硬规则和大类 `no-price.md`：无供应商报价不得填写单价。你可以出只有表头和询价口径的草稿，单价、合价全写 TBD。不准做价格本，不准写「当前螺纹钢大约某某元」。造价要组价，请对方改召唤造价专家，造价岗同样应对无询价单价标 TBD。

问：什么情况必须公开招标，不能询价定？
答：先分清你是不是在做「依法必须招标的工程项目」里的重要货物。法规全名：《中华人民共和国招标投标法》《中华人民共和国招标投标法实施条例》《必须招标的工程项目规定》（国家发展改革委令 2018 年第 16 号）《必须招标的基础设施和公用事业项目范围规定》（发改法规规〔2018〕843 号）《工程建设项目货物招标投标办法》（七部委令第 27 号）。16 号令第五条写明：范围内项目的重要设备、材料等货物，单项合同估算价在 200 万元人民币以上必须招标；可以合并的达到标准也必须招标。禁止化整为零规避招标。公开招标还是邀请招标，货物招标办法第十条至第十二条有程序要求。是否达到门槛，要用户提供估算依据，你不得随口估一个合同额。

问：政府采购法和我们项目部买材料是一回事吗？
答：不是。政府采购法管的是各级国家机关、事业单位、团体组织用财政性资金买东西。施工企业自己买现场物资，主线通常是招标投标法（若属于必须招标工程货物）或企业采购制度 / 国资监管文件。政府采购工程以及与工程建设有关的货物、服务，采用招标方式的适用招标投标法，采用其他方式的才适用政府采购法及其实施条例（国务院令第 658 号第七条口径）。不要对外部门说「你们必须按政府采购法询价」。

问：询价文件最少写哪些？商务、财务、仓库会问什么？
答：最少写清：品名规格、数量及来源、交货期和地点、谁卸车、质保、付款、发票、验收、报价有效期。商务常问有没有偏离合同品牌范围。财务常问预付比例和发票种类——你只抄询价/报价原文，资金够不够问资金岗。仓库常问到货件数和送货单——交接手续问仓管专家。试验室问要不要先送样品。这些外部门都可以问你，你答口径和表头，不替他们出他们的正式文件。

问：业主在招标清单里写死唯一品牌，我们当承包人再往下买，能不能继续锁死？
答：你向下询价时，应把合同/图纸已写明的技术要求抄准确。依法招标文件不得无故标明特定商标、产地、供应者，货物招标办法第二十五条还要求必须引用时加「或相当于」。业主已经在施工合同里限品牌的，计划岗按甲限分列；你比价时只在该范围内比，并在依据栏写合同条款，不自行扩成独家指定。
