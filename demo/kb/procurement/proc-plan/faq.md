# 采购计划 · 白话问答

问：采购计划和需用计划有啥区别？施工员提一张要料单，是不是就能买？
答：不是。需用计划是现场说「哪天、哪个部位、要什么规格、要多少」。采购计划是物资岗拿这张单，先分清甲供还是自采，再按提前期倒推最迟哪天必须询价、下单、到货、验收。现场没提需、图纸对不上、合同没写清谁买，采购计划对应格子就待填，不能靠脑子补数。

问：提前期到底怎么算？能不能统一写「提前一周」？
答：不能统一编天数。提前期是从「有人提需求」到「货到现场验收完」整段时间：审批、询价或依法招标、厂家生产、运输、见证取样有时还要等报告。商品混凝土和进口设备差很远。用户或供方没给周期，就写待填。计划岗若问这批料会不会挡关键线路，你只提供「最迟到货日待填 + 已知约束」，关键线路本身请改召唤总控/周月计划专家。

问：甲供、甲指、甲限、自采到底谁掏钱、谁担质量？
答：白话四句。甲供：业主买了送到现场，你清点保管，货权一般还是业主的，质量选型主要在业主，你漏检、保管坏了仍要负责。甲指：业主点名哪家厂，合同却常要施工方去签采购合同、去付款，货权和付款风险容易扯皮，必须把合同原文和有没有三方协议写清楚。甲限：业主给几个品牌或一个档次，你在圈子里选。自采（乙供）：你自己选、自己买、自己对质量交期负责。四类必须分行，禁止写在一格「材料」里。

问：业主口头说「就用某某牌」，我们要不要写进采购计划当甲指？
答：计划里可以记一笔「业主口头意向」，依据栏写「无书面」，不能当成已经改合同。按合同约定该由承包人采购的，《中华人民共和国建筑法》第二十五条写明发包单位不得指定生产厂、供应商。依法招标场景下，《中华人民共和国招标投标法实施条例》第三十二条也将「限定或者指定特定的专利、商标、品牌、原产地或者供应商」列为不合理条件。计划稿只提示边界，不替法务下「违法/合法」结论，也不替商务改合同。

问：办公打印纸、矿泉水算不算采购计划？
答：不算本岗正本。工程主材、周转、劳保、现场危化品才进本表。办公接待问行政会务后勤。塔吊汽车吊证件和司机证问设备管理。钢筋复试取样问试验室。你可以把「劳保安全帽」列进工程采购计划，但不要把食堂食材写进来。

问：数量从哪来？能不能按经验估？
答：数量只能来自用户给的图纸、清单、需用单或明确口述。无来源就 `[Axxx]` 待填。禁止用「一般项目都按 1.05 损耗」编出一个总量。损耗系数企业有制度且用户出示的，可以当口径引用并注明来源；没有就空着。

问：外部门问「这批钢筋什么时候到，会不会停工？」怎么答？
答：先看采购计划里有没有到货节点和供方确认的交期。没有书面交期就说「尚未收到供方交期，节点待填」，不要安慰说「问题不大」。进度会不会停工，要计划岗和调度拿关键线路判断。你只提供物资约束，不替现场下停工令。
