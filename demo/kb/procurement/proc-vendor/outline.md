# 供应商专家 · 独立成稿骨架

标题：「供应商准入 / 考察 / 评价表（AI 草稿 · 内部讨论）」。一次写全表头，缺证照、缺考察记录就待填，禁止编造营业执照号、证书号、业绩合同额。

1. 封面与目的：本次是新供方准入、既有名录复评、项目短名单，还是退出建议。项目名称、物资品类、编制人空栏。标明 AI 草稿。
2. 草稿声明：用公司 disclaimer。本表不是中标通知、不是合格证、不是可以进场施工的许可。
3. 准入资料目录（有原件/复印件/系统截图才勾，没有就「未提供」）：
   - 营业执照、法定代表人身份证明
   - 与所供货物匹配的生产或经营许可（用户未指出法定许可种类则写「许可种类待核对」，不编许可证号）
   - 质量管理体系等自愿性证书（未提供不写「已通过」）
   - 近年限类似业绩（只摘用户交来的合同封面/中标公告，无则待填）
   - 安全生产、环保相关许可（危化品、民爆、特种设备制造等按品类列，不套用到普通砂石）
   - 授权经销、售后网点、检测报告/型式试验（按品类）
4. 初审：证照是否在有效期、经营范围是否覆盖本包、是否被用户提供的失信/高风险名单列明。只记录用户出示的名单名称，不联网「查询后认定」。
5. 现场考察提纲（去了才填，没去就整节待填）：厂址与库容、生产线是否与样品一致、原材料来源、检测设备是否在检定期、成品堆场、发运能力、质量管理记录抽查。考察人、日期、照片编号留空给用户。
6. 短名单 / 合格供方名录口径：列「拟入名录 / 仅本项目短名单 / 观察期」。央企语境可对照《关于规范中央企业采购管理工作的指导意见》（国资发改革规〔2024〕53 号）——建立合格供应商名录并动态管理、量化考核、分级；不得把「未纳入高风险名单」当成参与采购的基本资格条件，不得排斥潜在供应商。
7. 评价表表头（无履约事实不打分）：供货批次、规格符合、到货及时、资料齐全、售后响应、配合取样复试、安全文明、价格只作「有无书面报价」而不填金额。权重待企业制度。禁止在无送货记录时编「质量优、交期好」。
8. 动态与退出：质量事故、虚假资料、无故断供、拒绝配合复试，列事实和证据编号。退出建议写「提请按企业制度审议」，不写「已清退出库」。高风险名单只引用用户已有制度，不新造黑名单。
9. 与询价、计划、试验的接口：未准入是否允许被询价（按企业制度，制度待填）；甲指供方是否仍要走资料建档；厂家报告交给试验室，取样结论不由本岗改写。

禁令：不编业绩和证书编号；不因关系户省略考察栏；不把「能进名录」写成「已中标」；评价不打价格分（无报价可评）；不替代特种设备许可或危化品经营许可本身。
