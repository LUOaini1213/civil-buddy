# 招标解析私库 · 摘录清单

独立完成时按表抽取，缺项标「招标未写」：

| 字段 | 说明 |
|------|------|
| 项目名称 | 封面或公告 |
| 招标人 | |
| 工期 | 日历天 |
| 质量标准 | 合格 / 其他 |
| 资质要求 | 施工总承包等级 |
| 类似业绩 | 年限、金额、类型 |
| ★响应项 | 标注星号或「不满足即废标」 |
| 必须编制的专项 | 临边、深基坑、模板、起重、有限空间等 |
| 评分点 | 技术标分值结构 |

输出一份 Markdown 表即可独立交差给经营经理讨论。

## 表怎么填才算交差

每一行只允许三种填法：抄招标短句、写「招标未写」、写「见补遗第×号（用户已粘贴）」。禁止第三种：「按惯例 365 天」「一般要一级建造师」「控制价大概两千万」。金额、天数、等级全部来自用户粘贴的公告、须知前附表、评标办法前附表或清单封面。

建议把上表扩成工作底稿，避免漏项：

| 扩列字段 | 抽取位置 | 填法 |
|---|---|---|
| 代理机构与监督部门 | 公告末页 | 无则招标未写 |
| 招标范围一句话 | 公告或须知 | 不扩写范围外专业 |
| 资格预审还是后审 | 公告 | 预审项目另摘资审办法 |
| 是否允许联合体 | 须知 | 允许则摘各方资质是否可叠加 |
| 项目负责人专业/等级/社保/在建 | 资格条件 | 与人事台账对照，本岗不编证号 |
| 评标方法名称 | 评标办法前附表 | 综合评估 / 经评审最低价 / 地方合理低价 |
| 形式、资格、响应性标准 | 前附表三行 | 原文要点，不改词 |
| 技术分构成 | 施组分+机构分+其他 | 分值照抄 |
| 最高限价或控制价 | 公告或清单 | 无数字则 TBD，不估算 |
| 清单能否改名称数量 | 评标办法或清单说明 | 多数标准文件改了即否决 |
| 暂列金额 / 暂估价 / 甲供 | 清单汇总 | 只列项，不组价 |
| 保证金金额形式账户 | 须知 | 无账户则招标未写 |
| 投标有效期 | 须知 | 与保证金有效期对照 |
| 暗标与否、信封数量 | 须知及附表 | 交给技术标和废标检查 |
| 书面澄清截止 | 时间轴 | 过点不再建议「打电话问问」 |

## 工程量清单解析口径

《建设工程工程量清单计价规范》GB 50500-2013 公开要点：清单是招标文件组成部分，准确性和完整性由招标人负责。解析岗发现项目特征空白、单位矛盾、图纸与清单不一致，动作为「列入澄清建议」，不是替招标人改量。投标人私自增加子目、合并子目、改计量单位，废标检查会按未响应处理。无定额无询价时，本岗连参考单价都不写。

## 评分办法怎么读

先读前附表，再读正文。前附表与正文冲突时，在摘录表注明「冲突，待用户确认以谁为准」，不擅自选对投标人有利的那一版。技术标分值结构要拆到「行」，例如：施工方案完整性、进度计划、质量保证、安全文明、机械劳动力、项目管理机构。每一行交给技术标变成一节目录。不要把「其他因素」吞掉。

## 红线

不编业绩；不编证书；不把政府采购评分办法套到工程招标；不输出「建议投标/建议放弃」的决策句，只给缺口。法规对照用全名+年份，不贴条文。
