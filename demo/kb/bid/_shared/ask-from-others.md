# 外部门怎么问经营投标

本文件给施工、商务造价、财务、安质、人事、行政同事用。经营投标大类只召唤三个已建专家：招标解析（bid-parse）、废标检查（bid-compliance）、技术标（bid-tech）。不要另开「报价专家」「法务专家」——单价与组价归商务造价岗，法规只报公开名称与年份口径，不粘贴规范或法条全文。

## 问之前先备齐什么

至少说清四件事，否则本岗只能回「招标未提供正文」：

1. 项目名称、招标人或代理机构、递交截止时间（精确到时分）。
2. 你手里有没有招标公告、投标人须知、评标办法前附表、工程量清单、图纸目录。没有的就说「只有公告」或「只有截图」。
3. 你真正想知道的是：能不能投、会不会废、技术标写什么、要哪些人证章、钱和保证金怎么走。一次只问一类，避免把「资质够不够」和「专项谁写」搅在同一句。
4. 本企业已有材料：营业执照、资质证书、安全生产许可证、类似业绩台账、拟派项目负责人证书。没有附件就写「待企业库补」，禁止口述一个编号让专家当成真的。

## 该找哪位，不要找错人

| 你的问题类型 | 召唤谁 | 对方会给你什么 |
|---|---|---|
| 工期、质量、资质等级、类似业绩年限、评分办法是综合评估还是合理低价、清单能不能改、必须编哪些专项 | 招标解析 | 摘录表 + 「招标未写」缺口 |
| 章、签字、联合体协议、保证金、★项、超限价、附加条件、暗标露名 | 废标检查 | 已响应 / 未响应 / 招标未提供正文 |
| 技术标目录、施组章节、危大专项是否列入、项目管理机构表怎么填 | 技术标 | 按评分点排的目录草稿 |

施工现场同事最常问「这个专项到底写不写进标书」。先问招标解析有没有把它列为必须编制或评分点，再问技术标怎么落目录。不要直接让技术标替你发明一项招标没要的专项。

财务同事最常问「保证金打多少、从哪出、什么时候退」。先把招标文件里投标保证金金额、形式、账户、有效期原文要点转述给废标检查，不要让经营岗估算一个「大概百分之二」。公开口径只提醒：依法必须招标项目里，招标人若收保证金，常见上限口径见《招标投标法实施条例》（2011 公布、2019 修订）相关条款精神——具体数字以本项目招标文件为准，专家不代填账号和金额。

商务造价同事问「清单漏项怎么报」。招标解析只拆口径、标 TBD，不编综合单价。组价、取费、增值税列项去商务造价岗。

人事同事问「项目经理能不能换、证书能不能借用」。本岗只核对招标对注册专业、社保、在建限制的响应口径，不帮你编证书、不承诺「可以挂靠」。

## 经营部反过来要问你们什么

- 问施工：现场平面、工期是否可承诺、危大工程清单是否与招标专项一致、拟派班组是否真实。
- 问商务造价：控制价/最高限价、暂列金额与暂估价、清单特征描述是否被改过。
- 问财务：保证金账户、保函还是转账、投标有效期内资金能不能冻住、中标服务费预算。
- 问安质：安全文明评分点对应的现场措施能否落地，禁止技术标写现场做不到的承诺。
- 问行政：营业执照、开户许可、授权委托、密封袋、电子章与纸质章是否双套齐。

## 红线（外部门也要知道）

- 不编造企业业绩、合同额、证书编号、中标通知书。
- 无清单、定额、询价：只出拆分口径，单价一律 TBD。
- 不把「整场废标」说成「我们这家废了」，也不把「单家投标无效」说成「这次招标取消了」。
- 不向施工承诺「按这个目录写完就能中」；不向财务承诺「保证金一定退」。
- 澄清提问截止、投标截止、开标时间以招标文件及补遗为准，口头传闻不算。
- 成果一律标明「AI 草稿 · 内部讨论」，不替代正式投标文件、不替代授权签字。
