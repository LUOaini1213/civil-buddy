# 生产调度 · 联网口径（2026-08-14 现场）

岗位对应：调度日报草稿。不是法定 site record，不是监理指令。不编产量、台班、气温。

辖区：默认新加坡工地（SG）。用户 pack 另指定则从其指定。禁止静默混用 CN / SG。本页不是规范全文库。

## CN

- 施工日志 / 调度日报是企业或资料习惯，不是 37 号令文件。37 号令只标 CN，且不管调度日报格式。
- 《危险性较大的分部分项工程安全管理规定》（住建部令第 37 号，2018-03-08 公布，2018-06-01 施行）。司法部转载：https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/201803/t20180329_146159.html ；济南住建转载全文（页标 2024-09-26）：https://jncc.jinan.gov.cn/col116284/art/2024/art_116284_4780280.html
- 《中华人民共和国安全生产法》（2021 第三次修正）。应急管理部转载（来源中国人大网）：https://www.mem.gov.cn/fw/flfgbz/fg/202107/t20210716_416558.shtml
- 《建设工程安全生产管理条例》（国务院令第 393 号，2004-02-01 施行）。国家能源局华北监管局转载：https://hbj.nea.gov.cn/xxgk/fdzdgknr/hbjgfl/flwj/202311/t20231105_196004.html
- 配套公开文件只写全名：建办质〔2018〕31 号《关于实施〈危险性较大的分部分项工程安全管理规定〉有关问题的通知》。只标 CN。

公开口径：危大定义、专项方案、交底、监测与验收档案是危大管理，不是调度日报法定格式。本岗不把调度稿写成 37 号令档案、监理指令或复工令。

## SG · 法定现场记录 ≠ 调度日报

- Building Control Regulations 2003 r.22 Site records：supervising QP 须在工地保存文件与簿册，包括（大工程）三个月结构工事进度表、QP/现场监督出勤、site record book、批准结构图、浇筑检查、缺陷修补、SI 报告、桩与各类试验记录、监测等。https://sso.agc.gov.sg/SL/BCA1989-S666-2003
- BCA Construction site records（页更 2026-01-29）：site and test records 须在施工期间留在现场。试验室须 SAC-SINGLAS。https://www1.bca.gov.sg/safety-and-standards/applications-and-licenses/permit-for-structural-works/construction-site-records/
- 上述是 QP / site supervisor 的法定档案，不是承包商调度日报，本岗不冒充已归档原件。

## SG · 协调会与日报习惯

- WSH (Construction) Regulations 2007：SSO 目录实有 Part II Site coordination meeting（由 project manager 主持）。现行版对本日 2026-08-14。https://sso.agc.gov.sg/SL/WSHA2006-S663-2007
- MOM WSH 总入口：本轮主站部分页面维护。https://www.mom.gov.sg/workplace-safety-and-health
- 公共工程合约条件（金额超 S$1 million）含定期报告 WSH 表现。https://www.mom.gov.sg/workplace-safety-and-health/safe-measures/sectoral-level/wsh-requirements-in-public-sector-construction-and-construction-related-projects
- PSSCOC 是公共工程标准合约（BCA 发布；页更 2026-03-14）。现有 PSSCOC for Construction Works 2020（第 8 版）/ PSSCOC-lite for Construction Works 2025（2025-03）等版本。索赔侧有 contemporary records 口径，全文条款未抽则 UNSPECIFIED。https://www1.bca.gov.sg/growth-and-transformation/procurement/standard-contract-forms/public-sector-standard-conditions-of-contract-psscoc/
- 业界 site diary / daily report 习惯字段（非法定表格）：日期班次、天气对作业影响、人员与分包、机械开停、材料到货、当日工作面与完成情况、访客/指令、延误停工、明日条件。数量仅用户或台账给出才写。

## 通用 禁令

- 不把调度稿写成 r.22 site record book 或「隐患已消除可以开工」。
- 形象进度叙事交项目日报；计划网络交计划专家。天气、人数、方量无来源则表头 + TBD。
