# 测量专家私库 · 常见问答

控制网、放样、复测记录口径。用户没给坐标、高程、限差，一律不编。禁止给出「复测合格」「精度满足规范」而无用户/PDF 数字。高风险成稿需确认门；纯提问可白话解释。不粘贴 GB 50026 或行业测量规范全文。

## Q 外行问：工地测量到底在干什么？

三句话：先把「整个场地的尺子和方向」定住（控制网），再把图纸上的墙、柱、坑边「搬到地上」（放样），过一段时间再测一遍看桩有没有被碰歪（复测）。测错了，房子会偏、坑会挖错、预制件对不上。所以本岗不编造坐标。

## Q 控制网、控制点是什么？

控制点是场地上埋好的、有已知坐标或高程的固定点，分成平面控制点和高程控制点。许多点连起来并观测检核，就是控制网。施工常用层次：业主/勘察交来的首级点 → 场区加密 → 建筑物轴线控制网。现行国家标准名称可写《工程测量标准》GB 50026-2020，条款未核实则 UNSPECIFIED，不要默写等级限差。

没有用户提供的点之记、坐标表、高程系统（如 1985 国家高程、地方独立、施工假定），本岗只出表头，坐标列写 `[Axxx]`。

## Q 放样、放线、定位有何不同？

工地常混用。口径：

- 定位：把建筑物外廓轴线交点（角桩）测设到地面。
- 放线 / 细部放样：根据角桩放出各轴线交点、墙边、洞口、基础开挖边线（常撒白灰或弹墨线）。
- 放样：更泛，包括平面位置和高程（标高）测设。

顺序白话：接桩复测 → 建立施工控制 → 定位 → 开挖边线 → 基础/垫层轴线标高 → 向上投测轴线、传递高程 → 每层细部。

## Q ±0.000、标高、高程是一回事吗？

不完全是。高程一般相对某个高程基准面；标高是施工图上的相对高度。±0.000 是设计指定的室内（或某层）相对零点，要换成场地高程必须有用户给的换算关系。没有换算式不要把「一层地面」随口写成某个绝对高程。

## Q 轴线、轴线控制桩、龙门板是什么？

轴线是图纸上的定位基准线（如 ① 轴、A 轴）。挖槽时角桩会被挖掉，所以要把轴线延长到槽外安全处做标志：轴线控制桩，或传统的龙门板。向上施工还要把轴线投到楼层：外控法从场外控制桩往上瞄，内控法从楼内预留孔往上/往下投。用哪种、孔在哪、限差多少，必须来自用户方案或正式标准，不编毫米限差。

## Q 复测、检核、闭合差，外行怎么理解？

- 复测：过一段时间或施工关键节点，再测控制点，看有没有被碾、冻、挖。交接桩之后第一次复测尤其重要。
- 检核：一次放样后用另一方法或另一条路线测回来对一下。
- 闭合差：从一点出发绕一圈或附合到另一个已知点，理论上应闭合，实际会有差。这个差叫闭合差。差太大说明测错或点位动了，应停下来查，不要「调一调数字让它平差好看」。

导线（连成折线测边测角）看角度闭合差、全长相对闭合差；水准（测高差）看高差闭合差。限差数字必须来自用户指定的规范条款或项目测量方案，本库不默写。

## Q 后视、前视、站、转点呢？

把仪器支在一个点叫设站。先瞄一个已知点把方向或高程「接上」叫后视；再瞄要测的新点叫前视。中间临时过渡点叫转点。后视瞄错，整站都会错——所以记录表要留下后视点名、读数、仪器高，方便别人复核。

## Q 交接桩要注意什么？

业主、勘察或前一手施工单位把控制点交给项目，应有书面点之记、坐标高程、通视说明，现场指认。接收方复测，成果双方签认后才能当施工起算。本岗可出交接/复测记录表头，不编造点号和坐标，不写「复测合格、可以使用」。

## Q 为什么不能用手机导航坐标直接放样？

手机消费级定位误差通常是米级，建筑物轴线要的是毫米到厘米级，而且坐标系、中央子午线、投影面往往不是手机地图那一套。RTK/GNSS 可以做施工控制或放样，但必须有已知控制点校正、坐标系统转换和检核，仪器和账号信息由用户提供。没有这些，只列「拟采用卫星定位」待填。

## Q 沉降观测、基坑监测和施工放样是一回事吗？

不是。放样是「按图把点放到实地」。沉降/位移监测是「过一段时间看它动了没有」，常用独立的基准点、测点和频率。37 号令里部分危大工程还要第三方监测，那是监测单位的方案，本岗不编预警值，也不写「监测正常、可以继续开挖」。用户把监测和放样混在一问里时，分开答，监测预警交危大/施工方案/监测资料，本岗只谈控制点和记录口径。

## Q 记录表最少要有哪些栏？

日期班次、天气、工程部位、坐标系与高程系（用户给的名称）、使用仪器及编号、检定有效期（用户给）、观测者/记录者/复核者空签名栏、点名、后视、前视、仪器高、读数、计算出的坐标或标高、检核较差、备注（遮挡、振动、阳光、桩被碰）。计算过程有来源才写「公式 → 代入 → 结果 → 单位」。无数据就空表，不要填示范坐标。

## Q 什么时候该停测、不往下报成果？

控制点被破坏或对不上；闭合差明显超用户给定限差；仪器检定过期或气泡不稳；暴雨、大风、旁站振动影响读数；图号与现场对不上。停测原因写入记录，不要改数凑合格。

## Q 什么问题该换人问？

结构尺寸对不对、钢筋是否够 → 结构。基坑变形报警值、支护设计 → 岩土/施工方案。危大要不要论证 → 危大识别。明日谁去放线、和土方班怎么交叉 → 生产调度。本岗不编施工进度保证。
