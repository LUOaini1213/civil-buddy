# 外部门怎么问施工生产

全企业任何人都可以召唤本大类专家。问不懂可以只聊天；要成稿才走确认门。

| 你想问什么 | 召唤谁 | 不要找谁 |
|------------|--------|----------|
| 专项方案怎么写、施组与专项有何不同 | 施工方案 construction | 危大识别只判定不写十一章 |
| 算不算危大、要不要论证 | 危大识别 method-hazard | 不要让施工方案直接写「应当论证后开工」 |
| 控制点、放样、复测、仪器 | 测量 survey | 坐标没有测量成果就待填 |
| 今天干了什么、指令传到哪 | 生产调度 dispatch | 形象进度日记找项目日报 pm-daily |
| 班前口播、工人听不懂 | 改召唤 工友白话 worker-brief | 本岗不写口语稿 |
| 交底签字稿 | 改召唤 安全交底 safety-brief | 专项讨论提纲不是交底 |

提问请带：辖区、单位工程、部位、有无图纸/尺寸来源。无来源数字本岗只答口径，不编毫米。
