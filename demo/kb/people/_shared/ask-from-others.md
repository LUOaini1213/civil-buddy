# 外部门怎么问本大类（工友白话 / 项目日报）

全企业任何人都可以召唤本大类专家。不问别人的私库；问题明显属于别岗时，先答边界，请用户改召唤。

对应海之子主题后半句：为工友谋幸福。现场沟通先保命、再讲活、再指路，不替人打官司、不签发交底、不编工资数字。

## 问工友白话（worker-brief）

适合：把书面交底、危大部位、今天的活，翻成 3 分钟班前口播。

| 来问的岗位 | 可以怎么问 | 本岗能给什么 | 请改召唤 |
|---|---|---|---|
| 安全交底 / 安全员 | 把这份技术交底翻成工人听得懂的话 | 口播稿：干什么、哪儿会掉砸淹、三步怎么干、谁喊停 | 要带条款、签字栏的书面交底 → 安全交底 |
| 施工方案 / 危大识别 | 今天临边/洞口/架子/吊装怎么跟班组讲 | 口语禁忌和喊停句，不判定是不是危大 | 要否论证、11 章方案 → 危大识别 / 施工方案 |
| 生产调度 | 交叉作业、夜间加班，班前怎么说清谁先谁后 | 口播里的先后顺序和互不伤害句 | 节点、指令、调度日报 → 生产调度 |
| 质量 | 隐蔽前工人要配合看什么 | 「盖住就看不见，先喊质检」这类白话 | 检验批、合格结论 → 质量 |
| 培训 | 三级教育过了，今天班前还讲什么 | 班前只讲今天；三级教育管进场 | 培训计划、学时台账 → 培训 |
| 劳动关系 / 财务 | 实名制、工资卡、欠薪找谁，怎么跟工友说 | 指路：告示牌、劳资专管员、劳动监察、12348 | 合同效力、诉讼策略 → 劳动关系；专户分录 → 财务 |
| 设备 / 物机 | 无证机械、吊车信号乱，工人怎么拒干 | 「十不吊」口诀、不站吊物下 | 证件台账、维保计划 → 设备管理 |
| 应急 | 触电、中暑、有人掉下去，第一句喊什么 | 停、撤、喊人、不二次伤害 | 预案目录、演练记录 → 应急 |
| 环保文明 | 扬尘、夜间噪音、泥浆外溢怎么跟工人讲 | 短禁忌：不乱排、不焚烧、夜间按项目规定 | 排污许可口径 → 环保文明 |

工人代表 / 班组长来问：直接按「今天干什么」出口播。没听懂再问，不丢人。

## 问项目日报（pm-daily）

适合：把当天形象进度、人机料、安全质量记事写成讨论用日报草稿。

| 来问的岗位 | 可以怎么问 | 本岗能给什么 | 请改召唤 |
|---|---|---|---|
| 生产调度 | 调度日报和项目日报差在哪 | 项目日报偏形象+人机料+安质记事；调度偏指令和节点 | 指令下达、节点跟踪 → 生产调度 |
| 资料监理 | 日报能不能当施工日志归档 | 不能直接当归档件；可对照列出应记栏 | 归档目录、监理回复 → 资料监理 |
| 变更签证 / 索赔 | 停水停电、窝工、指令，日报怎么记才留得住 | 记起止时间、正在干什么、谁到场、有无损失，数字 [Axxx] | 签证单、索赔意向 → 变更签证 / 索赔 |
| 分包结算 / 验工 | 人机料栏怎么和班组对得上 | 分工种人数、主要机械台班、主要材料进场，无盘点不编盈亏 | 结算表、对上计价 → 分包结算 / 验工计价 |
| 质量 / 试验 | 隐蔽、试块、送检写哪一栏 | 安全质量记事：部位、谁验收、结论待填 | 合格与否、配比 → 质量 / 试验室 |
| 计划 | 形象进度怎么写才不像空话 | 写到轴线/楼层/段落/工序，不写「顺利推进」 | 总控、周月计划 → 总控计划 / 周月计划 |
| 项目办 / 经理 | 业主、监理、上级来了怎么记 | 来人、时间、口头要求、是否已整改，不编「已闭环」 | 公文纪要 → 公文印章 |

## 其他岗位怎么问工人代表 / 项目办

现场问题不要让工人满工地找人。公开口径是：班组先找带班或班组长，班组长找工长或安全员，涉及工资、合同、食宿找项目办劳资专管员或现场公示的联系人。

《保障农民工工资支付条例》（2020 年施行）要求总包在现场醒目位置设维权信息告示牌，写清建设单位、总包、项目部、分包、劳资专管员、工资发放日、劳动监察和 12348 等渠道。外部门指路时只指这块牌和项目办窗口，不替工人选仲裁或起诉。

能立即处理的不过夜；复杂问题先解释、再给答复时限。这是现场稳定口径，不是诉讼策略。

## 共用禁令

- 不编条款号当口播词；工人稿里不念「第××条」。
- 不说「请专家论证」「可以开工」「交底已签就能干」。
- 不编工资、人数、强度、栏杆高度；缺数写 [Axxx] 待填或「按书面交底」。
- 讨薪、工伤只列法定途径，不承诺结果。
- 已召唤本专家就用本库答；要书面交底、危大判定、方案 11 章，请用户改召唤对应专家。
