# 项目日报 · 联网入口（2026-08-14 现场）

岗位对应：项目日报 / site diary / 施工日志公开口径。草稿不是归档施工日志，也不是监理日志或索赔裁决。大类门户见 `_shared/web-knowledge.md`。

辖区：默认新加坡工地（SG）。用户 pack 另指定则从其指定。禁止静默混用 CN / SG。未抽出原文的标准只写全名，条款 UNSPECIFIED。2026-08-14 已打开 BCA Construction site records。

## CN

- 烟建建管〔2022〕9 号：施工员及时做好工程施工记录、隐蔽工程记录和签证，**逐日填写施工日志**。https://www.yantai.gov.cn/art/2022/4/15/art_58501_3080490.html
- 黑建工〔2025〕4 号：专职安全员每日填写《安全日志》，视频与日志保存至竣工验收；危大、隐患、特种作业持证写入日志。https://zfcxjst.hlj.gov.cn/zfcxjst/c114765/202504/c00_31829450.shtml
- 南建建〔2025〕13 号：安全员逐日规范填写《施工安全日志》；特种作业持证巡视写入日志。https://www.nanan.gov.cn/zwgk/zfxxgkzl/bmzfxxgk/zfhcxjsj/zfxxgkml/202506/t20250613_3179604.htm
- 行业公开写法（西工大基建处转载，不是国标）：施工日志按**单位工程**、从开工记到竣工、逐日不断、人员变动要交接，通常由栋号工长记；内容分基本、工作、检验、检查、其他。安全日志当天记、不后补、隐患与整改闭合。https://jijian.nwpu.edu.cn/info/1056/3229.htm
- 只写全名：《建设工程文件归档规范》GB/T 50328-2014；《建设工程监理规范》GB/T 50319-2013；条款 UNSPECIFIED

## SG

- BCA 页题 *Construction site records*（页更 2026-01-29）：施工期间现场保管 site and test records。含 3 个月结构进度表、QP 与现场监督出勤、**site record book**（现场监督记在场时间、意见与指令）、批准结构图、浇筑前检查、缺陷修补、地勘、桩试、水泥砂石、砼试块、钢筋/预应力试验等。试验须 SAC-SINGLAS 认可实验室。清单 https://go.gov.sg/site-form 。本岗项目日报不是这份法定现场簿。https://www1.bca.gov.sg/safety-and-standards/applications-and-licenses/permit-for-structural-works/construction-site-records/
- SAC-SINGLAS：https://www.sac-accreditation.gov.sg/services/accreditation-services/laboratories/
- MOM CSMS（2018-10-24）：Toolbox Meeting、Induction、行为观察可电子记录主持/出席/议题；日报只摘「班前是否开过」，不替安全系统建档。https://www.mom.gov.sg/-/media/mom/documents/safety-health/csms-system-integration-data-guidelines.pdf
- RE / RTO 岗位公开描述常要求维护 daily records / site diary（试验、检查、进度、劳动力、材料），属合同监督惯例，不是本岗签发件。

## 通用提醒

- 本岗项目日报服务项目办日清：形象进度 + 人机料 + 安质记事。不要冒充施工日志、安全日志、监理日志或 BCA site record book。
- SG 先写 site record book / daily records；CN 才写施工日志 / 安全日志。DUAL 分栏。
- 不给报审通过、监理已同意作业、隐患已全部消除、产值与评优。无来源数字 [Axxx]。
