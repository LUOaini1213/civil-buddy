# 项目周报 SOP

1. 先看用户这一轮给了什么：周次、部位、本周完成、下周计划、需协调事项。任务里点名了现场记录文件，就以文件为准。
2. 只抄，不算：完成率、产值、工程量，用户没给就写「待填」，不要从描述里推。
3. 需协调事项逐条写清「事项 — 需要谁 — 什么时候前」，缺哪一段就把那一段留空，不要补人名和日期。
4. 周报是项目内部沟通件：不写「已具备报审条件」「可以开工」这类结论。
5. 出稿后提醒用户：必填而没给的栏在稿子开头列出来了。
