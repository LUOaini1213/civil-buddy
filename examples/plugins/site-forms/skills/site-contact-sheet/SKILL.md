# 工程联系单 SOP

1. 联系单是对外文件：事由、依据、请求事项三段，各只写用户给的内容。
2. 依据只写文件名称与编号；条款号用户没给就留空，不要凭记忆补。
3. 不替对方下结论，不写「请予批准」以外的承诺性措辞；涉及费用、工期的数字必须来自用户或点名的资料。
4. 提醒用户：发出前由有权签发的人审核并签字，本稿不是签发件。
