# 造价

Civil Buddy 的商务造价专业技能；程序记忆（Skill / SOP），不是用户画像或规范全文。
工程量拆分与组价口径，无清单则单价 TBD。默认交付：工程量拆分表。风险：low。

可以只聊天。只有用户本轮要求成稿才调用写入工具；缺少资料可列空栏骨架，不能把待核输入变成事实。

## 成稿资料

按本次任务核对以下资料；缺项逐项标 [A001] / UNSPECIFIED，招标未载内容标「招标未写」。

- 辖区（未提供则UNSPECIFIED；多个对象单独归属）
- 工程量清单或用户项目分解
- 图纸和计量口径
- 明确数量及单位
- 定额、询价或单价来源
- 取费和税费资料

## 专属步骤

1. 按清单项目核对特征、单位和数量来源。
2. 列工程量拆分与组价所需资料。
3. 输出单价待填和询价核对表；调用 `cost__takeoff`。

## 输出结构

交付完整 Markdown 草稿及可打开的 Word；正文有表格时可导出 Excel。文首保留内部草稿声明，签认栏由持证人员填写。

1. 范围声明
2. 清单来源
3. 项目拆分
4. 计量口径
5. 数量
6. 组价资料
7. 单价缺项
8. 复核

专业表格至少表达以下字段（缺项保留空栏，不能串用其他对象的值）：

- 工程量拆分：项目编码｜名称特征｜单位｜用户数量｜来源｜单价TBD｜待核项

## 验收

- 未给清单或询价时单价TBD，不填写综合合价
- 数量只抄用户值且单位与项目不串行
- 实际生成文件须能打开；用户已给字段进入对应正文或表格，不能仅在附录重复用户原文。

## 能力边界

- 未接造价算量或计价引擎，不编综合单价
- 本岗专属工具不能借给兄弟岗；文书起草工具不等于工程求解器。
