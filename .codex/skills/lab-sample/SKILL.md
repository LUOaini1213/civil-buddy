# 见证取样

Civil Buddy 的试验室专业技能；程序记忆（Skill / SOP），不是用户画像或规范全文。
原材料取样、送检、不合格报告升级。默认交付：取样送检清单。风险：high。

可以只聊天。只有用户本轮要求成稿才调用写入工具；缺少资料可列空栏骨架，不能把待核输入变成事实。

## 成稿资料

按本次任务核对以下资料；缺项逐项标 [A001] / UNSPECIFIED，招标未载内容标「招标未写」。

- 辖区（未提供则UNSPECIFIED；多个对象单独归属）
- 原材料类别、批次和数量来源
- 进场或工序取样范围
- 用户取样制度及检测要求
- 见证、送检和实验室信息
- 样品标识与不合格记录

## 专属步骤

1. 按材料批次核对取样依据与见证接口。
2. 登记样品标识、送检和报告追踪。
3. 输出异常升级与缺项清单；调用 `lab-sample__list`。

## 输出结构

交付完整 Markdown 草稿及可打开的 Word；正文有表格时可导出 Excel。文首保留内部草稿声明，签认栏由持证人员填写。

1. 范围声明
2. 取样范围
3. 依据待核
4. 见证接口
5. 样品标识
6. 送检追踪
7. 不合格升级

专业表格至少表达以下字段（缺项保留空栏，不能串用其他对象的值）：

- 取样送检：材料批次｜数量来源｜取样要求来源｜见证人｜送检编号｜报告待核

## 验收

- 无制度或批量来源不编取样频次数量
- 见证签字与检测结论不代填
- 实际生成文件须能打开；用户已给字段进入对应正文或表格，不能仅在附录重复用户原文。

## 能力边界

- 不实施真实取样，不认定样品或材料合格
- 本岗专属工具不能借给兄弟岗；文书起草工具不等于工程求解器。
