# 订舱工作流策略

1. 先可行性与 can_fit，再谈订舱话术。  
2. 报 N0 与 binding（weight/volume）。  
3. 双口径同时给 booking% 与 outer%。  
4. TMS stub 提交不改 layout。  
5. VGM 草稿须人签。
