# 幕墙项目投标应答策略（窄）

1. **先红线后文案**：资格与废标项未清，不生成长篇技术标。  
2. **交付可核验**：运输包装条款用装柜 Agent 结果作附件，不空口。  
3. **人签商务**：价格、业绩、授权、盖章仅人工。  
4. **偏离透明**：做不到写「偏离/澄清」，禁止幻觉覆盖。
