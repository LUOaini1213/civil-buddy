# 第四章 采购需求

一、服务范围：道路及附属设施养护、排水管道及检查井疏通养护、泵站运行维护、桥梁日常巡查、应急抢修及防汛保障。

二、服务要求

1. ★供应商接到抢修指令后，须在2小时内到达现场并采取安全围护措施。

2. ★须配备不少于2台套路面养护车和1台管道疏通车，并在响应文件中提供设备权属证明。

3. 道路坑槽应在发现后48小时内修复，修复面积按实计量；井盖缺失、破损应在发现后4小时内完成临时防护。

4. 汛期（每年6月1日至9月30日）实行24小时值班，泵站运行人员每班不少于2人。

三、考核办法：采购人每月考核一次，每季度汇总；季度考核得分低于75分的，采购人有权解除合同。
