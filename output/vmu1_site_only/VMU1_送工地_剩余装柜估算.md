# 你的柜型（COSCO 铭牌）+ VMU1 送工地柜数

## 柜型参数（按你提供的铭牌）

| 项 | 铭牌读数 | 含义 |
|---|---:|---|
| **MAX.WT** | **32,500 kg** | 柜最大总重（货+柜皮） |
| **TARE** | **3,890 kg** | 空柜皮重 |
| **PAYLOAD** | **28,610 kg** | **最大货重**（= 32500 − 3890） |
| **HIGH** | **2.9 m** | 外高（高柜 HQ） |
| **CU.CAP** | **76.4 m³** | 柜内容积（≈ 2,698 cu.ft） |

→ 这是标准 **40HQ**。程序里已同步：`max_load_kg=28610`，容积 `76.4 m³`。

---

## 两个约束怎么用（都要）

```text
柜数 = max(
  ceil( 货重合计 / 28,610 kg ),     ← 重量
  ceil( 有效货体积 / (76.4 × 可用率) )  ← 体积
)
```

| 约束 | 正确用法 | 错误用法（我之前的问题） |
|------|----------|--------------------------|
| **重量** | 货重 ≤ 28.61 t/柜 | — |
| **体积** | 真实件堆叠 + 合理包装 ≤ 76.4 m³×可用率 | 用虚大「当量箱外廓」累加 → 体积被卡死 → 柜数虚高 |

钢结构/铁件常见：**重量先到、体积仍空**（利用率看起来只有 30–40% 也正常）。  
体积约束在，但**不能把分子算虚大**。

## 对照 REDACTED-REF 装货单（领导 2 柜）

| 柜 | 装货单 | 货重约 | vs PAYLOAD 28.61 t |
|---|---|---:|---|
| 1 | 7-20装货单1柜 | **≈ 19.8 t** | OK（&lt; 28.61） |
| 2 | 7-20装货单2柜 | **≈ 12.7 t** | OK |
| **合计** | | **≈ 32.4 t** | 重量上 **ceil(32.4/28.61)=2 柜** |

体积：两柜共约 **152.8 m³** 几何容积；铁件实装已进 2 柜，说明 **76.4 m³/柜 够用**，不是体积不够。

## 结论

- **你的柜子**：COSCO **40HQ**，货重上限 **28.61 t**，容积 **76.4 m³**  
- **工地铁件（REDACTED-REF）**：**2 柜**（与领导一致；单柜都未超 28.61 t）  
- 算法：重量、体积 **都约束**；要改的是 **体积别算得太狠**，不是取消体积约束  

公路/码头若另有限重，以更严者为准（铭牌 PAYLOAD 是柜本身上限）。
