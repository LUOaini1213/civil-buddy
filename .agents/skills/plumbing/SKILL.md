# 给排水

Civil Buddy 的勘察设计专业技能；程序记忆（Skill / SOP），不是用户画像或规范全文。
给水、排水、消防水量原则，无标高不编管径。默认交付：给排水说明草稿。风险：low。

可以只聊天。只有用户本轮要求成稿才调用写入工具；缺少资料可列空栏骨架，不能把待核输入变成事实。

## 成稿资料

按本次任务核对以下资料；缺项逐项标 [A001] / UNSPECIFIED，招标未载内容标「招标未写」。

- 辖区（未提供则UNSPECIFIED；多个对象单独归属）
- 系统范围与单体
- 水源、水压及市政接驳资料
- 室内出户和市政井标高
- 器具或用水负荷资料
- 消防水和机电提资

## 专属步骤

1. 逐系统登记水源、接驳与标高来源。
2. 梳理给水分区、排水雨水及消防水界面。
3. 列选泵管径计算输入和待核图纸；调用 `plumbing__memo`。

## 输出结构

交付完整 Markdown 草稿及可打开的 Word；正文有表格时可导出 Excel。文首保留内部草稿声明，签认栏由持证人员填写。

1. 系统范围
2. 草稿声明
3. 水源接驳
4. 生活给水
5. 污废水
6. 雨水回用
7. 消防水
8. 特殊部位
9. 节水
10. 专业接口

专业表格至少表达以下字段（缺项保留空栏，不能串用其他对象的值）：

- 接驳与标高：系统｜接管点｜市政水压｜出户标高｜市政井标高｜来源｜缺项

## 验收

- 不同系统的水压标高不串值
- 无器具当量、流量和计算书时选泵管径保留UNSPECIFIED
- 实际生成文件须能打开；用户已给字段进入对应正文或表格，不能仅在附录重复用户原文。

## 能力边界

- 未执行水力计算，不以原则稿替代消防水或给排水设计
- 本岗专属工具不能借给兄弟岗；文书起草工具不等于工程求解器。
