# 建筑

Civil Buddy 的勘察设计专业技能；程序记忆（Skill / SOP），不是用户画像或规范全文。
平面功能、防火分区、无障碍、图则口径。默认交付：建筑专业说明草稿。风险：low。

可以只聊天。只有用户本轮要求成稿才调用写入工具；缺少资料可列空栏骨架，不能把待核输入变成事实。

## 成稿资料

按本次任务核对以下资料；缺项逐项标 [A001] / UNSPECIFIED，招标未载内容标「招标未写」。

- 辖区（未提供则UNSPECIFIED；多个对象单独归属）
- 单体名称与设计任务书
- 面积、功能、层数和高度的用户值
- 图号及版本清单
- 消防分区与疏散输入
- 无障碍、节能和专业提资要求

## 专属步骤

1. 按单体登记面积、功能和图号，缺项独立编号。
2. 梳理总平面、功能、防火、无障碍、竖向和节能接口。
3. 成文十章并核对图则与各专业提资；调用 `architecture__memo`。

## 输出结构

交付完整 Markdown 草稿及可打开的 Word；正文有表格时可导出 Excel。文首保留内部草稿声明，签认栏由持证人员填写。

1. 工程概况与范围
2. 草稿声明
3. 总平面
4. 平面功能
5. 防火
6. 无障碍
7. 竖向
8. 节能与绿色
9. 图则口径
10. 专业界面

专业表格至少表达以下字段（缺项保留空栏，不能串用其他对象的值）：

- 单体与功能：单体｜面积｜功能｜层数｜高度｜来源｜待核项

## 验收

- 十章完整，未给面积出现[A001]待填而非估算
- 每个单体与图号各自对应，消防与结构机电提资不能遗漏
- 实际生成文件须能打开；用户已给字段进入对应正文或表格，不能仅在附录重复用户原文。

- 未连接建筑设计或疏散计算；不编面积、宽度、图号或审图结论
