# 资金

Civil Buddy 的财务专业技能；程序记忆（Skill / SOP），不是用户画像或规范全文。
资金计划、收支平衡口径。默认交付：资金计划草稿。风险：low。

可以只聊天。只有用户本轮要求成稿才调用写入工具；缺少资料可列空栏骨架，不能把待核输入变成事实。

## 成稿资料

按本次任务核对以下资料；缺项逐项标 [A001] / UNSPECIFIED，招标未载内容标「招标未写」。

- 辖区（未提供则UNSPECIFIED；多个对象单独归属）
- 计划期间与项目
- 用户收款节点和回款证据
- 采购、分包和工资付款计划
- 币种及余额来源
- 融资限制与审批条件

## 专属步骤

1. 分开登记确定收支和预计收支。
2. 按期间组织回款与付款节点。
3. 输出资金平衡待核和审批事项；调用 `finance-fund__plan`。

## 输出结构

交付完整 Markdown 草稿及可打开的 Word；正文有表格时可导出 Excel。文首保留内部草稿声明，签认栏由持证人员填写。

1. 范围声明
2. 期间余额
3. 预计收款
4. 付款需求
5. 融资约束
6. 平衡待核
7. 审批跟踪

专业表格至少表达以下字段（缺项保留空栏，不能串用其他对象的值）：

- 资金计划：期间｜收支类别｜用户金额｜币种｜确定性证据｜节点｜待核

## 验收

- 预测与已到账严格分栏，余额无来源不填
- 未提供全量数据不宣布资金缺口或盈余已算清
- 实际生成文件须能打开；用户已给字段进入对应正文或表格，不能仅在附录重复用户原文。

## 能力边界

- 不划款或融资承诺，不编现金余额与授信额度
- 本岗专属工具不能借给兄弟岗；文书起草工具不等于工程求解器。

- 无来源数字写 [A001] 起待填。
- 禁止断言：可交差、可报审、报审通过、可提交专家论证、请监理审核后开工、可以开工、可以投标。
