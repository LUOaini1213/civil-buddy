## Architecture gaps vs the bar

1. **Only one expert is 易标-aligned (`construction`)**. yibiao-map `aligned: true` count = 1 / 65.
2. **Category-shared tools leak sibling exclusives** (bid parse/compliance/tech all visible to every bid expert). 易标 modules are separate workspaces (OpenBidKit “业务模块” list).
3. **No 查重 module** (explicit in both OpenBidKit README and yibiao.pro).
4. **Parse is bid-only**; drawings/specs/lab certificates have no MinerU-class ingest.
5. **Word/落盘** beyond md is construction-only; peers advertise one-click Word.
6. **SG** is implemented on the aligned writer only; CN 37-order / JGJ tone remains in construction shared KB.
7. **MCP is one binary + filters** (correct vs 16 OS processes) but unaligned exclusives are names without execute.
