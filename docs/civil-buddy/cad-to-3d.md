# CAD → 3D 建模助手（预览）

将 **已确认用途的二维实体轮廓 + 用户给定的高度或长度** 转成真实三角网格，
在浏览器里旋转、缩放、选择构件、修改参数，再导出 GLB 和参数记录。
首版同时提供建筑平面、构件截面两种模式。两者共用确定性几何程序，
命令解析器只修改受限参数，不调用模型，不执行生成的 Python，不编造顶点。

这是几何预览工具；没有完整的 Revit/BIM 构件语义，不能作为设计签认件。
仓库附带的两份图纸是**合成测试样例**。目前没有用户实际项目 CAD 的验收结果；
样例和自动测试通过不代表任意施工图都能转换。

## 启动

在项目环境安装基础依赖和 CAD 依赖，然后启动工作台：

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-cad.txt
python -m packing_assistant.civil app
```

打开工作台首页的「CAD → 3D 建模助手」，或在工作台地址后访问 `/cad`。
CAD 附加依赖为 `ezdxf`、`shapely`、`trimesh`、`mapbox-earcut`。
没有安装时，页面会显示所需的安装命令。

## 两种模式

| 模式 | 明确输入 | 建模结果 | 参数修改例子 |
| --- | --- | --- | --- |
| 建筑平面 | 墙体实体边界、柱子截面、楼板实体边界，分别对应已确认图层 | 单层墙、柱、板，各自按高度/厚度和底标高拉伸 | `墙和柱高3米，楼板厚120毫米` |
| 构件截面 | 同一图层内的外轮廓及内孔边界，用户指定拉伸长度 | 保留贯通内孔的棱柱类构件 | `把拉伸长度改为6米` |

这些例子中的尺寸来自用户输入。系统不会从房间名称、图层名称、图片或相邻构件
推测建筑高度、板厚、截面长度。墙的平面厚度取自原轮廓，不在首版参数命令中改写。

**不要把房间边界当成墙体实体。** 如果一条封闭轮廓围住整个房间而没有明确内外墙边界，
直接拉伸会得到实心块。请先在二维视图核对图层和轮廓的含义；无法确认实体区域时不要生成。
图层名称只用于提出映射建议，用户必须确认用途及实体区域含义。

## 可接受的 DXF

- 直接上传 DXF；首版不导入 DWG。只有 DWG 时，请先用 CAD 软件另存为 DXF。
- 建模实体必须是闭合、直线组成、零线宽的 `LWPOLYLINE` 或二维 `POLYLINE`。
  位于世界 XY 平面，原图 Z 为 0；高度与底标高在建模面板指定。
- 必须确认原图单位，支持毫米、厘米、米、英寸、英尺。
  单位缺失或不明确时不猜测；界面参数统一换算为米。
- 单独的 `LINE`、弧线/曲线、带 bulge 的多段线、带宽度的笔画、块引用、非平面轮廓等
  不作为实体边界。不会自动补线、把弧改直线或修复自交轮廓。
- 同一建模图层内，轮廓相交、重合、相切，或者混有无效/不支持实体时，
  **该图层整体标记失败**。请在原 CAD 中清理或分层，以免漏掉内孔边界后把空洞填实。
- 同一图层内严格嵌套的边界按内外包含关系保留贯通孔洞。
  孔洞随所属实体一起拉伸，不能单独修改孔洞高度。
  不同图层的对象各自独立，不自动做布尔合并或洞口扣减。

门窗洞口自动识别、楼梯、屋顶、多层对齐、复杂曲面和任意施工图自动还原不属于首版能力。
未处理的实体会显示状态和原因；请查看报告，不要只检查三维画面是否出现。

## 操作顺序

1. 上传 DXF。二维视图显示原轮廓和图层，同时查看解析结果及未支持实体。
2. 选择「建筑平面」或「构件截面」，确认原图单位，指定各图层为墙/柱/板/截面/忽略。
3. 输入对应角色的高度、板厚或拉伸长度，以及底标高。
   确认所选轮廓代表实体区域后生成模型。
4. 在三维视图旋转、缩放和平移，选择构件查看来源图层、原图实体编号和参数。
   查看成功、忽略、失败的逐实体记录；部分图层失败会在记录中保留。
5. 在面板或命令框修改参数，确认预览更新。撤销返回此前的参数状态。
6. 导出前完整键入：`我明白，将由持证人员签认`。
   可以下载 GLB、参数 JSON，或同时包含两者的 ZIP。

预览只要求确认轮廓的实体含义，不需要签认句。导出生成可带走的文件时，服务端也会检查
上述完整签认句，不能用勾选框或命令解析替代。

图纸与模型使用临时预览缓存，服务重启会清空，保存约 30 分钟；缓存满时较早的项目可能
提前释放。过期后需重新上传并生成。请及时导出，保留原始 DXF 和参数记录。

## 参数命令

支持有限、完整匹配的中文和基础英文指令。距离必须有明确单位，多个修改可以用逗号或
分号连接；所有子句都成功才返回修改后的参数。有一句不能识别或校验失败，整条消息不生效。

| 目的 | 指令 |
| --- | --- |
| 统一墙高 | `把墙高改成3.6米` |
| 同时改墙与柱 | `墙和柱高3米` |
| 改楼板拉伸厚度 | `楼板厚120毫米` |
| 改柱底标高 | `把柱子标高改为0.2米` |
| 只改选中实体 | `把选中构件高度改为3米` |
| 修改截面构件长度 | `把拉伸长度改为6米` |
| 过滤已有用途 | `只建墙和柱` |
| 忽略指定图层 | `忽略 FURNITURE 图层` |
| 多个修改一起生效 | `墙高3.6米，柱高3米，楼板厚120毫米` |
| 英文参数修改 | `set walls and columns height to 3.6 m` |

角色级修改会同步该角色已有构件的同名覆盖参数，例如改全部墙高后，曾单独设过高度的墙
也采用新高度；它们的底标高和其他参数保留。只改一个构件时，请先选中该构件再下指令。

「只建」仅过滤已经确认的用途，不会把未指定用途的图层猜成墙或柱。「忽略」使用实际图层名；
例如图纸中的 `FURNITURE` 不会因为用户写了「家具」而被自动翻译匹配。恢复被忽略的用途、
新增映射、确认单位、切换模式请用参数面板。

问题、否定、缺单位、零或负高度、非有限数值、互相冲突的多个值以及未知动作均拒绝执行。
例如 `墙高3米吗`、`不要改墙高3米`、`墙高3.6`、`墙高3米，墙高4米` 都不会改模型。
底标高允许用户明确给出 0 或负数。源图坐标、单位和实体确认状态不由命令修改。

## 文件与尺寸追溯

GLB 包含真实可重新加载的网格，长度单位为米，使用 Y 轴向上。内部预览几何采用 Z 轴向上；
导出进行确定的坐标轴变换。参数 JSON 记录原图名称与摘要、确认的单位、平移原点、
坐标轴映射、图层用途、角色参数、构件覆盖参数、来源实体编号、孔洞信息及处理报告。

为避免大坐标降低显示精度，预览会移动原点；移动量与单位换算都写入记录。
调高度不改变源图 XY 轮廓和预览原点；改选图层可能重定原点，新的平移量会记入记录。
被忽略的图层不会拉远预览原点。若多个选中构件相距过远，转为浏览器和 GLB 使用的
float32 网格时会损失薄壁尺寸，工具会明确拒绝失真图层，避免显示或导出被压扁的实体。
参数 JSON 不代替原始 DXF；要复核原图实体或重建模型，应同时保留两者。

## 验证与实际图纸验收

```powershell
python scripts/test_cad_commands.py
python scripts/test_cad_geometry.py
python scripts/test_cad_api.py
```

命令测试检查原图/配置不被修改、显式单位、角色及对象级修改、多子句原子性与拒绝情形。
几何测试负责尺寸、孔洞、闭合网格和 GLB 重新加载；接口测试负责请求和导出边界。
测试不访问真实模型服务。

真实图纸到位后，建筑平面与构件截面应分别完成下列验收：

- 人工确认原图单位、实体区域和至少一组可复核尺寸，检查模型尺寸没有千倍缩放错误。
- 检查明确的内孔仍为空洞，未实现的门窗等在处理记录中可见。
- 修改一个高度或长度，核对平面轮廓和其他构件参数保持正确，并测试撤销。
- 导出 GLB 后用独立查看器重新打开，核对尺寸、方向、对象数量和参数记录。
- 逐项核对忽略与失败的实体，记录原图中不符合首版条件的内容。

只有对应实际图纸完成这些检查，才能报告该场景验收通过。
