## 二、分项对照（联网）

### 1）集装箱/CTU 侧（不是铁架本身，但是出运环境）

CTU Code 强调：

- 货载分布、集中载荷要传到 **结构构件**（纵/横梁），必要时用 **timber/steel beams 卸荷**  
- 吊装/绑扎点强度与布置；重心宜居中，横向偏心宜小  
- 地板与作业载荷限值（集装箱底板 CSC 等）  

**你们系统：**

| 点 | 现状 | 评审 |
|----|------|------|
| 成箱后载荷上限 | `max_payload_kg` + 净重检查 | 对齐「不超设计载荷」 |
| 局部承压/垫板 | `check_local_bearing`，详设可设垫板 mm | 对齐「小足迹重货要垫」方向 |
| 柜内偏心/COG | **在 risk/loader**，不在结构 Agent | 正确：铁架结构 vs 柜内配载应分拆 |
| 柜底 CSC 轮压等 | **未做** | 属集装箱操作，可文档声明「箱外」 |

**结论：** 结构模块管 **包装铁架**；柜内 CTU 规则在 **风险/装载**，架构合理。

### 2）木箱/货架类简化设计（行业手册）

USDA *Wood Crate Design Manual* 等长期实践：

- 压杆按 **长细比 L/d 或 λ** 分短柱/中柱/长柱  
- 挠度与叠加堆码（顶面 psf）常要单独验  
- 安全系数与冲击/长期荷载折减常合并考虑  
- **没有绝对单一公式**，设计含 SF 与工况假定  

**你们系统：**

| 点 | 现状 | 评审 |
|----|------|------|
| 立柱 λ=L0/i | 有，钢允许约 150，警惕带 80～120 | 与钢结构经验同量级 |
| 底板弯矩 M=qL²/8 | 简支均布 | 标准筛查级，节点固接会偏严/偏松视模型 |
| 挠度 L/200 | 有 | 常用限值之一，合理 |
| 顶载/堆码 psf | **基本未做** | 若铁架堆码二层箱，缺口 |
| 冲击/运输动载 | 用 γ 放大（如 >2t → 2.2） | 方向对，但非完整加速度谱 |

### 3）安全系数 γ

行业包装/托盘：

- 托盘等常用 SF≈2～2.8（试验极限/使用载荷）量级  
- 运输包装常把 **保证水平 / 冲击** 放进系数  

**你们：** 默认 γ≈1.8，重箱 2.0～2.2，详设可写死。  

**评审：** 作 **筛查偏安全** 可接受；若声称符合某国标具体条文，需条文编号与分项系数表，目前 **没有**。

### 4）吊装

工程习惯：多点吊、对称、单点力不宜过大；吊具本身常另按 **高 SF** 选。  

**你们：** 点数≥4 或轻箱、偏心系数粗检，**不算卸扣/焊缝/钢丝绳**。  

**评审：** 作 **布置合规提示** OK；**不能**代替吊装专项计算。

### 5）截面与详设（你们已加强的部分）

| 要求 | 实现 | 联网/工程评价 |
|------|------|----------------|
| 可追溯截面 | `design_facts` + `steel_table` / sectionproperties | 正确方向 |
| 无详设不装正式 | 结论 **待详设** + 风险 block | 符合「详设事实」业务 |
| 自然语言改截面 | `/api/revise-nl` | 利于人机协同改方案 |
| 表值近似 | 型钢表为近似值 | 必须标注；正式用国标表覆盖 |

## 三、与代码一一对应的「符合 / 不符合」

### 符合事实方向（保留）

1. **分阶段**：Agent2 建议 → 成箱后 `run_structure_calc` 硬结论  
2. **载荷超限即不通过**（超 `max_payload`）  
3. **四类检查**：几何、底板、框架、局部、吊点（知识库 mandatory 方向）  
4. **详设覆盖默认截面**，并记录 drawing_no / source  
5. **柜内 COG/偏心在 risk**，不与铁架计算混为一谈  

### 不符合或弱于「详设事实」（须对外说清）

| # | 问题 | 行业期望 | 你们 | 风险 |
|---|------|----------|------|------|
| 1 | 稳定系数 φ(λ) 完整曲线 | 钢结构规范分条 | 粗取 fb×0.7 | 可能误通过/过严 |
| 2 | 焊接节点/加劲肋 | 图纸细部 | 无 | 不能签章 |
| 3 | 运输动载（纵横垂向 a） | CTU/船级加速度 | 仅 γ | 海运工况不足 |
| 4 | 堆码顶载 | 木箱手册 psf | 弱 | 二层堆码铁架 |
| 5 | 吊具与焊缝 | 吊装规范高 SF | 只数点 | 吊装专项缺口 |
| 6 | 型钢表精度 | 国标型钢表 | 近似表 | 须覆盖 |
| 7 | 试验验证 | 压溃/振动试验（ISO 等） | 无 | 不可替代试验 |

### 业务策略评审（对你们产品）

| 策略 | 评价 |
|------|------|
| 无详设 → **待详设** 且不可出运 | **正确**，逼输入事实 |
| 自然语言改截面重算 | **正确**，贴合「人改方案」 |
| 半严格力学 + 详设截面 | **可接受为工程筛查 + 可追溯参数**，勿称 FEA/签章 |
